# ADR-0003：敏感样本按分级准入，默认不入共享库

- 状态：`proposed`
- 日期：2026-09-16
- 决策者：Owner（周健）
- 依赖：ADR-0001（双账本）

## 背景

「内部正面与负面样本库」按会议设计要包含：
> 负面：投诉、下架、警告、返工、达人争议、审核争议

这类素材**天然含敏感内容**。实测当前 8 条可见样本已经出现：

| 分类 | 品线 | 内容 |
|---|---|---|
| 反例 | 婴幼儿监视器 | **画面中婴儿口含硬币**，北美文化视为危险行为 |
| 反例 | 吸奶器 | 品牌定位是"赋能与从容"，**图文传递的情绪与品牌调性严重违背** |
| 反例 | 清洗机 | 绝对化用语（100%、绝不），违反广告法 |
| 反例 | 吸奶器 | 文案意思不对，类似上次疏通堵塞那个意思。 |

前两条是**真实的品牌风险素材**：一条涉及儿童安全隐患画面，一条涉及品牌调性内部判断。
它们用于内部合规学习是合理的，但一旦进入：
- 一个**共享**的多维表格
- 一个**接入 LLM** 的 Agent 的上下文
- 一份可能被引用的报告

……就会产生原本没有的风险。

**当前没有任何分级机制。** 8 条样本直接躺在表里，谁有表权限谁就能看到全文。

## 决策

引入**三级敏感度**，每一级有明确的**准入边界**（不是"注意一下"，是准入/不准入）。

| 级别 | 定义 | 谁能看原文 | 能否进 Agent 上下文 | 能否进报告 |
|---|---|---|---|---|
| `L0 公开` | 已发布的公开内容本身 | 全体 | ✅ 原文 | ✅ 可引用 |
| `L1 内部` | 内部判定结论、规则、措辞 | 项目成员 | ✅ 原文 | ✅ 可引用 |
| `L2 敏感` | 含品牌风险画面、客诉原文、个体信息、未公开判断 | **仅指定人** | ⚠️ **仅脱敏摘要** | ❌ 仅可引用编号 |

**三条硬规则：**

1. **默认 `L2`。** 样本入库时未标注级别的，一律按 `L2` 处理。
   宁可让人多标一次，不可让敏感素材默认外流。
2. **`L2` 素材的原文永不进入 Agent 上下文。**
   Agent 只能拿到 `<sample-ref id="S-012" level="L2"/>` 加一段人工写的脱敏摘要。
3. **`L2` 素材在报告里只出现编号，不出现内容。** 需要引用时写「见 S-012」，不复制正文。

## 为什么不是「全部脱敏后统一入库」

- 脱敏会**销毁判定价值**：把「婴儿口含硬币」脱敏成「画面含不安全元素」，就丢失了
  具体是什么元素 —— 而这恰恰是复查和培训时最需要的部分。
- 脱敏是**不可逆的**：一旦原文没存，后面想重新看也不可能。
- 因此正确做法是**原文留着但控制可达性**，不是把原文改掉。

## 为什么不是「干脆不存」

不存等于放弃最有价值的资产。会议明确要求「内部错题库」，
且昨天审计已证明**团队真正的判定能力不在规则表里，在这些案例里**。
不存 = 把隐性知识继续留在大脑里，人一走就没了。

## 实施要点

1. 飞书侧：`正面和负面样本` 表增加 `敏感级别` 字段，并配字段级权限（飞书高级权限支持）。
2. 本地侧：快照拉取时，`L2` 记录的原文**只落在本地加密目录**，不进 git。
3. git 内只存 `L2` 的 `id + 级别 + 人工写的脱敏摘要`。
4. Agent 侧：工具层强制过滤 —— 返回 `L2` 记录时**只返回摘要**，
   并把「原文已被策略拦截」显式写进工具返回值（不能静默返回空）。

## 后果

**正面**
- 敏感素材可用于内部学习，但不会被无意传播
- Agent 可以在不接触敏感原文的前提下使用这些案例的**结论**
- 一旦发生争议，有明确的准入记录可查

**负面 / 代价**
- 入库多一道标注工序（但只做一次）
- Agent 对 `L2` 案例的理解会**弱于**原文（这是刻意接受的代价）
- 需要维护「谁能看 L2」的名单

## 待 Owner 确认的问题

1. **`L2` 的判定权归谁？** 建议：品牌侧 + 法务共同确认，不由开发者单方判定。
2. **谁能看 `L2`？** 需要一个具体名单（含未来加入的人怎么加）。
3. **现有的 8 条样本怎么定级？** 建议：其中「婴儿口含硬币」「品牌调性违背」两条定 `L2`，
   其余定 `L1` —— 需 Owner 与品牌侧确认。
4. 是否接受「未标注即按 `L2`」这条默认规则？
