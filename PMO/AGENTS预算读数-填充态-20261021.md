# AGENTS.md 预算读数：真实大小 vs stat（填充态）· 2026-10-21

> 问题：`verify_agents_budget.py` 用 `os.path.getsize` 读大小。
> 若注入方按**外部 stat**（填充态下多 4096）判断 65536 预算，两个读数会差 4096 ——
> 正好是一条教训的量级，而检查器会一直报「余量够」。
>
> **结论先行**：填充态在本环境**可复现**；`os.path.getsize` 返回真实值，外部 `stat` 返回 +4096。
> 检查器已改成 `max(real, stat)`，结论行同时报两个数。
> **注入方按哪个数判断：未测**（仓内无任何记录，见 §2）。

---

## 1. 三项读数实测

### 合成探针（临时目录，Python 写 10000 字节）

| 文件 | `os.path.getsize` | `len(open().read())` | 外部 `stat -f %z` | `wc -c` |
|---|---:|---:|---:|---:|
| `probe.md` | **10000** | **10000** | **14096** | **14096** |
| `probe.txt` | 10000 | 10000 | 10000 | 10000 |

- `.md`：stat = 真实 + **4096**，与 `PMO/填充态-环境特性-实测史.md` 的矩阵一致。
- `.txt`：不填充（该文档的矩阵里 `.txt` 也不命中）。
- `open().read()` 与真实一致；**stat 是另一个视图**。

### 真 `AGENTS.md`（2026-10-21 本机）

| 读数 | 值 |
|---|---:|
| `os.path.getsize` | **60835** |
| `len(open(...,'rb').read())` | **60835** |
| 外部 `stat -f %z` | **60835** |
| `wc -c` | **60835** |

★ **当前 `AGENTS.md` 没有填充**（四个读数一致）。派单里看到的 `stat 64931` 是当时的填充态，
今天已不在；但**特性仍在**（上面的 `.md` 探针每次都 +4096）。

## 3. 改成了什么

`tools/verify_agents_budget.py`：

- 新增 `_stat_size(path)`：**外部** `stat`（darwin `-f %z` / 其他 `-c %s`）；取不到返回 `None`。
- 新增 `sizes(path)` 与 `effective_size(real, stat)`：判定用 **`max(real, stat)`**。
- `check()` 的 B1：
  - 结论行同时报两个数：
    `AGENTS.md 60835B（stat 60835B）· 余量：按 real 4701 / 按 stat 4701（判定用 4701）`
  - stat 读不到 → **退 2（未测）**，不落绿。
- `--controls` 新增**填充态对照**：
  - Python 写一个 10000 字节的 `.md` → 断言 `stat == real + 4096` 且判定用 `stat`；
  - **造不出填充态 → 明说「未测」并退 2**，不假装验过。
- 原有行为级对照（`.txt` 造超预算文件）保持不变。

## 4. 反向对照

`--controls` 的输出（实测）：

```
✅ 填充态：real=10000 stat=14096 → 判定用 14096（必须是 stat）
```

（其余 6 条合成尺寸对照 + 行为级 `.txt` 对照保持原样。）
