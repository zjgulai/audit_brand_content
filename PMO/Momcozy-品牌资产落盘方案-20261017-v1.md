## 四、安全复制契约(`tools/cp_scf_smoke.sh`,通用工具)

```
对每一份文件(含 17 顶层 + 77 caption + 58 图)执行:

1. 写临时文件:dst.tmp.<pid>.<ts>
2. cp -p src → dst.tmp.<pid>.<ts>
3. 原子 rename:dst.tmp.<pid>.<ts> → dst(同一 fs 内 mv,POSIX 保证)
4. 校验:
   - stat(src).size == stat(dst).size         # size 恒等
   - shasum(src) == shasum(dst)               # sha256 恒等
   - 对图:magic-byte(JPEG/PNG/WebP)匹配扩展名
5. 冲突处理(已存在 dst):
   - dst.sha256 == src.sha256 → skip(不冲突)
   - 不一致 → 写 _logs/conflicts.jsonl,dst 加 .bak-<ts>,原 path 落 _quarantine/
6. 写 _logs/cp_<action>.jsonl(每动作一行 JSON,字段:ts, action, src_path,
   src_sha256, src_size, src_mtime, src_type, src_license_status,
   dst_path, dst_sha256, dst_size, status)
```

**全部完成后**跑 `python3 tools/verify_depad.py`(全仓 +4096 扫描)。

**license_status 强制** = `unknown`(fb 第 6 条;**不**因为"品牌资产"默认可公开)。

### §五.2 — 与 fb(同伴会话)的 8 条外部输入安全姿态

fb 的边界协议,逐条落进方案:

1. **Brand_agent/Momcozy/ 作为外部/不可信输入只读**(本仓库与 Brand_agent 是两个独立项目);
2. **不执行源脚本**(`lora_training_configs/*.toml` 与 `sref_candidates/*.png` 不调用、不解释);
3. **复制前记录 source_path / size / sha256 / mtime / type / series / license_status**(写入 _logs/* 与 manifest.json);
4. **目标写入用临时文件 + 原子 rename**(在同 fs 内 `mv` 取代 `cp -p`,见 §四);
5. **复制后逐文件 hash 恒等**(`shasum -a 256` 双向比对);
6. **不确定许可/敏感性标 `unknown`,不因"品牌资产"默认可公开**(顶层 17 文件与 58 张图 `license_status` 全写 `unknown`);
7. **不覆盖同名,冲突显式记账**(冲突写 `_logs/conflicts.jsonl`,见 Q9);
8. **结束前跑 depad + 给机器可读 manifest + 源/目标计数守恒**(`verify_depad.py` + `manifest.json` + 顶层 `manifest.json.files_count` 等于 `_logs/*.jsonl` 计数加总)。
