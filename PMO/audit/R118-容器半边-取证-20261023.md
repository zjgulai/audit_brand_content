## 四、产物通道：如果环境齐了，「能产出结果」要断言什么

先把判据写出来（**今天不能跑**，因为一/二/三都不齐）。每条都配一个反向对照，
避免又写出「喂空样本也绿」的假执行点。

### 4.1 图片（容器内）

| # | 断言 | 反向对照 |
|---|---|---|
| I1 | `ocr_text` 非空且长度 > 0；`parse_status = ok` | 1×1 纯白图 → 必须落 `failed/empty` 或显式 `untested`，**不得 ok** |
| I2 | 至少 1 个 `content_unit` 且 `has_text=true` | 空白图 → `has_text=false`，不得计入可判 |
| I3 | 判定跑通：`judge_entry` 返回五标签之一，`findings` 结构合法（7 字段齐） | 把 OCR 输出替换成空串 → findings 必须为 0 **且** `parse_status` 不得仍为 ok |
| I4 | `textification.extractor` **不是宿主原生**（不得以 `ocr_vision/VNRecognizeText` 开头），必须是容器内引擎标识（如 `tesseract/5.x`） | 把 extractor 改回 `ocr_vision/...` → 必须红（这条与静态半边 M1 同源） |
| I5 | 每个 finding 的 `location.bbox` 存在且非空 | 删掉 bbox → 必须红 |

### 4.2 视频（容器内）

| # | 断言 | 反向对照 |
|---|---|---|
| V1 | ASR 输出**非空**，且至少 1 个片段带 `start`/`end` | 全静音视频 → 必须显式 `untested/failed` + reason，不得 ok |
| V2 | 关键帧 OCR 至少 1 帧非空（`frame_no` + 文本） | 黑屏视频 → 显式 untested，不得静默空 |
| V3 | `covers` 五个键（字幕/内嵌文字/关键帧/音轨/完整画面语义）各有明确状态，**不许 null** | 缺任一键 → 红 |
| V4 | `video_stage()['$status']` 不再是 `cannot_measure`，且三个数字（获取成功率 / 识别完整度 / 处理耗时）都有读数 | 缺任一个数字 → 红（防止只把状态从 cannot_measure 改掉就交差） |
| V5 | 片段完整性：ASR 片段数 == 人工转写基线段落数（缺一段即红） | 删掉一段 → 红（这条同时是行 124 ① 的对象，等素材到位后两票共用） |

| # | 断言 | 反向对照 |

## 五、结论：暂时缺环境，还是结构性没有

| 通道 | 缺什么 | 性质 | 下一步 |
|---|---|---|---|
| docker | daemon 未启动（客户端/colima/lima 都在） | **暂时（环境）** | `colima start` ——需授权，本票不做 |
| 引擎 | 镜像里 0 个 OCR/ASR；宿主也没有 | **暂时（构建）** | 新建媒体镜像（apt 装 tesseract/ffmpeg + 模型权重）；Playbook TS-18/TS-19 的候选选型要先定 |
| 图片素材 | 有（834 张盘上） | 已具备 | 选一张可命中的作为夹具（`17db0b5cc32f86ce.png` 已验证） |
| 视频素材 | **0 个** | **结构性（数据）** | 需要业务提供真实短视频；上游 49 条视频广告只有文案，素材从未获取 |
| 容器化媒体链路 | 代码里没有容器引擎适配层（今天 `media.py` 调的是宿主 OCR） | **结构性（代码）** | 需要一层「容器内引擎」适配 + extractor 标识改造 |

**一句话**：行 118 的「无对象」是**两层** ——
**环境/构建**（docker 没起、镜像没引擎）是**暂时的**；
**视频素材与容器引擎适配**是**结构性的**（本架构里今天没有这两样）。
所以下一步动作也不同：前者补环境（可授权后做），后者要么补数据与适配层，
要么把验收表的这半句降级 —— **两者不能混成一句「没条件」**。
