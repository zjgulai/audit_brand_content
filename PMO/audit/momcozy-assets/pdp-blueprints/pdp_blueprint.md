# Momcozy PDP & Marketing 极致设计蓝图 (Squeeze-Dry Edition)

本文件定义了 Momcozy 官网高转化页面的底层视觉指纹。AI 在生成网页设计、详情页图片或营销 Banner 时，必须严格遵循此蓝图。

## 1. 详情页黄金逻辑 (The PDP Progressive Logic)
1. **[首屏] 情感锚点**: 
   - 视觉: 4:5 比例的 Lifestyle 摄影（母婴共处，自然光）。
   - 文案: 10字以内的 H1，强调“状态”而非功能（如: "Just You, Refreshed"）。
2. **[二屏] 技术解剖 (The 1px Tech Style)**:
   - 视觉: 产品 3D 渲染，背景半透明处理。
   - 元素: 使用 **1px 宽度** 的浅灰色标注线，端点为 **4px 实心小圆点**。
3. **[三屏] 感官网格 (Sensory Grid)**:
   - 布局: 2x2 或 3x1 图文块。
   - 图标: 2px 线条宽度的圆角线稿。
4. **[四屏] 真实共鸣 (Authentic Proof)**:
   - 视觉: 无滤镜、手机感、略带生活杂乱感的真实妈妈反馈图。

## 2. 视觉微偏好 (Micro-Design DNA)
- **留白 (Breathing Room)**: 每个视觉模块之间必须保持 **80-120px** 的垂直间距。
- **阴影 (Depth Logic)**: 严禁纯黑阴影。阴影色号应基于当前背景色加深 10% (e.g., `rgba(165, 113, 100, 0.1)` )。
- **指示文字**: 标注线末端的文字必须使用 **All-Caps (全大写)** 或 **Italic (斜体)** 以区分于正文。

## 3. 转化诱饵逻辑 (Conversion Hooks)
- **Badge 样式**: "Best Seller" 或 "New In" 标签应使用 **Pill Shape (全圆角)**，背景为品牌红 #E30022，文字为全白。
- **Bundle 逻辑**: 推广套装时，视觉上必须展示“产品 + 收纳包 + 护理附件”的合集感，并在价格旁标注 **"Mom's Value Pick"**。

## 4. 视频剪辑指纹 (Video Blueprint)
- **前 3 秒**: 必须是一个“痛点特写”（如：溢出的奶、宝宝在哭、妈妈疲惫的揉腰）。
- **中段**: 伴随节奏轻快的 Lo-fi 音乐，展示一键启动的动作。
- **结尾**: 展示妈妈喝咖啡、看书或平静微笑的画面，SLOGAN 居中跳出。
