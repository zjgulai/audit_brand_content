## 解决方案概述

### 为什么用 Image 2.0 → Seedance 2.0 工作流？

```
传统工作流:            新工作流:
文案 → 分镜 → 拍摄 → 剪辑    故事板 → 关键帧 → 视频
(2-3周)                 (2-3天)
```

**Image 2.0 优势**:
- 快速生成12宫格故事板，验证视觉叙事
- 低成本探索多种构图和情绪
- 可直接作为 Seedance 2.0 的首帧输入

**Seedance 2.0 优势**:
- 图生视频，保持画面一致性
- 支持镜头运动描述
- 适合社媒短视频节奏

### 两个产品的叙事策略

| 维度 | 暖奶器 (Bottle Warmer) | 消毒器 (Sterilizer Bags) |
|:---|:---|:---|
| **核心痛点** | 深夜等待奶温 / 温度不准烫到宝宝 | 消毒麻烦 / 担心细菌 / 外出无法消毒 |
| **情感锚点** | "夺回睡眠时间" | "每一口都安心" |
| **使用场景** | 深夜厨房 / 卧室床头 | 家中厨房 / 旅行酒店 / 外出露营 |
| **关键画面** | 暖光 / 妈妈疲惫但温柔的脸 / 宝宝满足 | 蒸汽 / 透明袋中洁净的奶瓶 / 妈妈放心微笑 |
| **VOC关键词** | fast, reliable, portable | affordable, easy, travel-friendly, sanity-saving |

## 工作流程详解

### Step 1: 12宫格故事板 (Image 2.0)

```
输入: 12个场景的文字描述
输出: 12张静态图 (建议比例 16:9 或 9:16)

操作:
  1. 打开 Image 2.0
  2. 选择比例: 视频用 16:9 (横版) 或 9:16 (竖版)
  3. 逐一生成12张故事板图
  4. 保存并编号: BW_Story_01 ~ BW_Story_12 (暖奶器)
  5. 保存并编号: ST_Story_01 ~ ST_Story_12 (消毒器)
```

### Step 2: 关键帧精选 + 增强 (Image 2.0)

```
从12张故事板中选出 5个最关键场景:
  - 开场钩子 (必须)
  - 产品登场 (必须)
  - 核心功能展示 (必须)
  - 情感高潮 (必须)
  - CTA/结尾 (必须)

对每个关键帧:
  1. 用增强版Prompt重新生成 (更高精度)
  2. 调整细节至完美
  3. 作为 Seedance 2.0 的首帧输入
```

### Step 3: 视频片段生成 (Seedance 2.0)

```
输入: 关键帧图片 + Seedance Prompt
输出: 5个视频片段 (每个3-5秒)

操作:
  1. 上传首帧图到 Seedance 2.0
  2. 输入对应的运动描述Prompt
  3. 设置运动强度: 中等 (建议)
  4. 生成视频片段
  5. 保存: BW_Video_01 ~ BW_Video_05
```

### Step 4: 后期剪辑

```
工具: 剪映 / Premiere / CapCut

操作:
  1. 按顺序拼接5个片段
  2. 添加BGM (Lo-fi beats / 轻柔钢琴)
  3. 添加字幕 (手绘感粗体字，品牌红#E30022高亮关键词)
  4. 添加品牌结尾帧
  5. 输出: 15-30秒成品视频
```

```
  "焦虑但真实"                   → 情绪
  "电影感纪录片风格，浅景深"      → 风格参考
```

### 镜头运动词汇表

| 中文 | 英文 | 效果 | 适用场景 |
|:---|:---|:---|:---|
| 缓慢推镜 | Slow push-in | 聚焦主体，增加紧张感 | 开场、产品登场 |
| 缓慢拉镜 | Slow pull-out | 展现场景，释放情绪 | 结尾、情绪高潮后 |
| 固定机位 | Static shot | 稳定观察，强调细节 | 功能展示、特写 |
| 轻微环绕 | Gentle orbit | 展示主体多角度 | 产品细节、人物 |
| 跟随 | Tracking | 跟随主体移动 | 运动场景、走动 |
| 缓慢平移 | Slow pan | 横向展开场景 | 场景切换、对比 |

### 运动幅度设置

| 幅度 | 适用场景 | 效果 |
|:---|:---|:---|
| 轻微 (Low) | 特写、慢镜头、情绪场景 | 几乎感觉不到运动，增强沉浸感 |
| 中等 (Medium) | 一般场景、产品展示 | 自然的运动，推荐默认 |
| 强烈 (High) | 动作场景、快速切换 | 明显的运动，适合快节奏 |

**推荐**: 喂养电器品类使用 **轻微** 或 **中等**，保持温柔舒缓的基调。

```
  4. 在剪映中拼接片段，添加BGM和字幕
  5. 导出并检查
  
然后重复上述步骤生成消毒器视频

预计总时间:

  Seedance生成: 1-2小时 (10个片段)
  后期剪辑: 1-2小时 (2条成品视频)
```
