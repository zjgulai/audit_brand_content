## 〇、三句话（先给结论，后面逐条给证据）

1. **PRD v2.0 与 Playbook v1.1 在同一份内容上会给出不同标签**：PRD 说语义命中「任何情况」都转人工；
   Playbook 允许满足 C1–C4 的语义 finding 直接 `confirmed`，而判定表对 `confirmed + L4 + 依据 ok`
   一律 `BLOCK`。两者不是措辞差异，是**同一个输入两种输出**。
2. **验收表条目 23/24 与 Playbook 的 C1–C4 一致**，但条目 24 追加了一条 Playbook 正文里没有的限制：
   「构图、暗示功效、调性、模特状态等画面语义类…**不得直接 confirmed 或直接产生 BLOCK**」。
   也就是说「验收表跟 Playbook」只对了一半。
3. **`machine_finalizable` 全仓只有 PRD v2.0 与 ticket 清单提到**，代码 / 数据表 / 配置 / 运行时读
   全部 0 命中。今天生产链的语义层是**常量桩**，所以「语义直 BLOCK」在运行时不发生 ——
   不是因为有一道闸，是因为**根本没有语义运行时**。

## 三、今天代码实际怎么做（行为级读数）

### 3.1 判定表对 `produced_by` 完全不看

用真实 `base/decision_table.decide()` 跑四组输入（`coverage=full`，`parse=ok`）：

| finding | 输出 |
|---|---|
| `produced_by=semantic`、`confirmed`、`L4`、`authority=ok` | **BLOCK / DP2** |
| `produced_by=rule`、`confirmed`、`L4`、`authority=ok` | **BLOCK / DP2** |
| `semantic`、`confirmed`、`L4`、`authority=missing` | REVIEW / DP3 |
| `semantic`、`candidate`、`L4` | REVIEW / DP3 |

**读数**：只要上游把它写成 `confirmed`，判定表对语义与规则**一视同仁**地 BLOCK。
判定层没有 `produced_by` 闸 —— C1–C4 必须在**上游**拦住。

### 3.2 C1–C4 的闸存在，但没有接进生产

- `base/semantic_judge.py:247-259 check_entity()`：逐条实现 C1（`judge_type=literal`）、
  C2（`object`/`attribute` 结构化）、C3（`can_recheck is True`）、C4（`location`）。
- `base/finding_store.py:176-186`：M1 —— `semantic` 直接 `confirmed` 必须带
  `confirmed_by_rule_class=true`，否则拒收。
- **但生产入口没有用它**：`base/judge_entry.py:138` 传的是常量
  `semantic_judge={"status": "untested", "findings": []}`；全仓 `semantic_judge` 的生产 importers
  为 0（只有 `tools/verify_*` 与 orchestrator 的形参）。
- 另有 `base/rule_class_registry.py` —— **不存在**（Playbook 技术方案要求「新建」，全仓只有
  `finding_store.py:178` 的一句注释提到它）。M2/M3 的按 `control_code` 开关、一致率统计与自动降级
  因此也没有对象。

### 3.3 所以「今天会不会语义直 BLOCK」

- **生产链路：不会**。因为语义层是常量桩，根本产不出 semantic finding。
- **判定层：会**。只要有一个 finding 带着 `produced_by=semantic, status=confirmed, L4, authority=ok`
  进来，判定表就 BLOCK —— 它不检查 C1–C4，也不检查 `confirmed_by_rule_class`（后者只在
  `finding_store.check_record` 里被校验，而生产判定链不经过 finding_store）。

这是一处**接缝**：M1 的闸在仓库层（finding_store），判定链不经过它；C1–C4 的闸在
semantic_judge，生产没用它。两道闸都在，但都不在**实际产生标签的那条路上**。
