## 四 · 决定一：报告要不要装 Node

这是唯一挡着「结案后能出报告」的事。

**事实**：唯一报告渲染器是 `tools/audit/report_render.mjs`（Node）。
生产镜像 `Dockerfile:36` 是 `python:3.12-slim`，**没有 Node**，
两个 `.mjs` 也不在 COPY 列表里。

**三个选项**：

| | 做法 | 代价 | 我的判断 |
|---|---|---|---|
| **A** | 运行阶段加 node | 需先实测 `libstdc++6` 依赖；可能引入 `apt-get`（当前 Dockerfile **0 处**） | **推荐**，但必须先跑下面的实测 |
| **B** | 移植成 Python | 违反「唯一渲染器」（`技术解决方案-v1.md:468` 明定 Node 实现以规避 Python 写盘 +4096）；`#37/#57/#58/#60/#61/#63/#67` 七行判据全挂在 Node 那份上 | **不推荐** |
| **C** | 报告改离线批处理 | 阶段门 D5 判据要改；`job_dispatcher` 今天也无生产消费者 | 可行但改变交付形态 |

**A 的第一步不是改 Dockerfile，是这两条命令**：

```bash
docker run --rm python:3.12-slim sh -c 'ldconfig -p | grep -c libstdc++'
docker run --rm -v /usr/local/bin/node:/n:ro python:3.12-slim /n --version
```

- 第 2 条**成功** → 直接 `COPY --from=web /usr/local/bin/node /usr/local/bin/node`，零额外依赖；
- **失败** → 要加 `apt-get install -y --no-install-recommends libstdc++6`，
  这会改变镜像供应链面，**那时 A 与 C 的代价要重估**。

我在这里不写「应该能跑」—— 沙盒里没有 docker daemon，我没实测过。
