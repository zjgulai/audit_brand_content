## 0. 这份规范解决什么问题

原 11 类不是按“审查动作”划分，而是按“内容主题/来源章节”划分，所以类名与逐条判定的主轴大面积错位。实测：638 条规则、11 个一级分类、58 个子类；把 `category-to-family-v1.json` 的 11→7 类级映射直接套到逐条判定上，只有 **416/638（65.2%）** 命中，**222/638（34.8%）** 会落错轴。4 个类完全不命中：证据与实质证明（类级映射 FACT，实际 76/78 是 CLAIM）、商品信息与Listing准确性（映射 FACT，实际 11/13 是 CLAIM）、品牌信任与声誉（映射 BRAND，实际 8/8 是 CLAIM）、北美本地化与标签要求（映射 FACT，实际 1/1 是 DISC，且辖区是 BR）。这 4 个类共 **100 条，其中 98 条与类级映射不符**。

子类层面同样不成立：35/58 个子类单轴（164 条，25.7%），23/58 被劈开（474 条，74.3%）；复核后单轴降至 29 个/125 条，被劈开升至 29 个/513 条（80.4%），真正“单轴且可执行”的只有 **27 个子类/123 条（19.3%）**。另有 **56/638（8.8%）** 根本不在七轴内：EDITORIAL 27 条、NOT_A_RULE 25 条、待拆分 4 条。对抗复核 86 条结论中 **31 条推翻（36.0%）**，最终 **42 条规则改判（6.6%）**；两轮对抗合计 115 项问题，点名 **18 条不同的双轴碰撞规则**。

因此本规范不再把“原一级分类”当路由，而是把分类拆成两层：**七主轴回答“这条规则要求审查什么、修复动作是什么”**；五个正交字段回答“义务形态、辖区、严重度、质量标记、主题”。只有先做预处理（去噪、白名单、聚合拆分、原子化），再按固定优先级判定，七轴才互斥且穷尽；未预处理前的七轴只是“带优先级的重叠”，这一点在 §6 逐条承认并处置。

## 1. 结构总览

### 1.1 七主轴

七主轴按**判定顺序**排列。顺序不是重要性排序，而是“前一道约束成立时，后面不再需要判定”的短路顺序：

| 顺序 | 轴 | 回答的问题 | 修复动作 | 需要的证据类型 |
|---:|---|---|---|---|
| 1 | **CHAN** 渠道控制 | 这条内容能不能在这个平台/地区/版位、以这种素材与提交形式投放？ | 换渠道、换版位、换素材、改提交字段；不能投放则拒登/下架 | 平台政策/法律条款原文 + 渠道元数据 |
| 2 | **RIGHT** 权利控制 | 使用这个真人、未成年人、AI 合成人物或第三方标识，授权链成立吗？ | 取得授权/同意、删除主体、替换素材、补 AI 标识 | 授权书、监护人同意、AI 生成记录、商标授权、核查记录 |
| 3 | **SCENE** 场景控制 | 内容演示/教导的动作与场景，受众照做会不会造成身体伤害？ | 改动作、改环境、改人群限制、加看护/防护、删除演示 | 动作四元组 + 安全边界来源（说明书/AAP/CPSC/EN 等） |
| 4 | **DISC** 披露控制 | 必须让受众看到/听到的信息元素 X，说全了吗？以规定形式出现了吗？ | 补披露、补限定、补风险提示、改显著度/位置/时长/音量 | 规则原文 X + 全载体检索记录 + 形式读数 |
| 5 | **BRAND** 品牌控制 | 即使事实全真、证据齐全，是否仍因调性、立场、情绪操纵或贬损竞品而不该这样说？ | 改口吻、改框架、去压力话术、去贬损、换立场 | 品牌语调规范/修订基线 + 完整上下文 + 活动真实条款 |
| 6 | **FACT** 事实控制 | 这句话说的知识、参数、功能、使用场景，与可核验事实一致吗？ | 改数字、改单位、改术语、改机制、改场景表述、补正来源 | 指南/系统综述/权威教科书/监管文件/规格书/实测记录 |
| 7 | **CLAIM** 宣称控制 | 这条对外宣称，拿得出与断言强度相称、可核查且范围匹配的证据吗？ | 补证据、降断言强度、删除宣称、改客观参数 | 测试报告、临床研究、认证文件、对比数据、授权与 COI 声明 |

**判定顺序的实质：**

1. CHAN 先于一切：渠道不允许，内容再真也不能投。
2. RIGHT 先于 SCENE：先问“能不能用这个人/这张脸”，再问“这个动作安不安全”。
3. SCENE 先于 DISC：先问“照做会不会受伤”，再问“有没有把风险说给受众”。
4. DISC 先于 BRAND/FACT/CLAIM：法定/政策要求的信息元素缺失，是独立的合规缺陷，不因主张为真或语气合适而治愈。
5. BRAND 先于 FACT/CLAIM：先做“事实全真、证据齐全”的反事实测试；问题仍在，说明缺陷在表达层。
6. FACT 先于 CLAIM：同一句既有事实错误又有证据不足时，先归事实；FACT 侧指不出具体矛盾来源或规格时，才让位 CLAIM。

### 1.2 五个正交字段

| 字段 | 回答什么 | 取值 | 是否决定主轴 |
|---|---|---|---|
| `rule_nature` | 义务形态是什么 | prohibition / mandate / disclosure / substantiation / recommendation | 否；正交，不可用主轴反推 |
| `jurisdiction` | 适用哪个法域/平台 | GLOBAL / US / CA / EU / UK / CN / BR / AU / SG / AT / BH / PLATFORM / MULTI | 否；只决定适用哪套标准 |
| `severity` | 违反后的影响多大 | L0–L5 | 否；由主轴+义务形态+影响面推导 |
| `quality_tag` | 是否只是形式/编辑质量问题 | TYPO / GRAMMAR / STRUCTURE / TERMINOLOGY / REFERENCE / IMAGE / FORMAT / READABILITY / LOCALIZATION | 否；永不占 primary |
| `topic` | 规则讲什么主题 | 源表主题，自由文本 | 否；只作描述与检索 |

`confidence`（high/medium/low）是**判定元字段**，不属于五正交字段；它表示“这次判定离人工复核有多远”，不是概率。

### 1.3 为什么主轴只有 7 个

七轴不是按主题分，而是按**修复动作**分。任何一条可执行规则，问“要修好它，必须做什么”，答案只能落在以下七类之一：

1. 换渠道/版位/提交形式（CHAN）；
2. 取得或撤销授权（RIGHT）；
3. 改动作或场景（SCENE）；
4. 补受众可见信息（DISC）；
5. 改表达/立场/语气（BRAND）；
6. 改与来源不符的事实（FACT）；
7. 补证据或降低断言（CLAIM）。

再加一类“不需要审查动作”的质量/非规则（EDITORIAL / NOT_A_RULE / 待拆分），以及一类“允许表达”（ALLOWED），就覆盖全部 638 条。再加第八个轴只会与上述七类之一重复；把原 11 类直接当轴则会产生 34.8% 的错路由。

七轴的有效分布高度集中：复核后 FACT 324（50.8%）、CLAIM 157（24.6%），两条合计 481/638（75.4%），在 582 条有效基数中占 82.6%；DISC 68（10.7%）为第三轴；CHAN 16、BRAND 11、SCENE 4、RIGHT 2 是长尾。长尾小不等于不重要：SCENE/RIGHT 包含 P0 一票否决项，不能按条数分配审查资源。

### 1.4 主轴与字段的分工

- 主轴回答**“这条规则要求哪一种审查动作”**；它决定派单给谁、需要什么证据、修复动作是什么。
- `rule_nature` 回答**“义务是禁止、强制、披露、举证还是建议”**；它不改变派单对象，但改变违规成立方式（做了才违规 vs 没做才违规）。
- `jurisdiction` 回答**“用哪套标准”**；同一句话在 US/EU/CN/BR 可以结论不同，但主轴不变。
- `severity` 回答**“多严重”**；它由主轴、义务形态、影响面三者推导，不能从原表 `severity_raw` 或 `p_level` 继承。
- `quality_tag` 回答**“是否只是形式问题”**；它永不占 primary，避免把“改错别字”伪装成审查结论。
- `topic` 只用于检索、聚合和报表，不参与判定。

实测证明主轴与 `rule_nature` 不正交是错的：复核后 FACT 中有 mandate 155、recommendation 125、prohibition 31、substantiation 11、disclosure 2；CLAIM 中有 prohibition 65、substantiation 51、recommendation 33、mandate 8；DISC 中 disclosure 48、prohibition 8、mandate 5、recommendation 4、substantiation 3。同一 `rule_nature` 横跨 Critical–Low，不能反推严重度。

## 2. 判定算法

### 2.1 输入与输出

```python
from dataclasses import dataclass, field
from typing import Literal, Optional

Axis = Literal["CHAN", "RIGHT", "SCENE", "DISC", "BRAND", "FACT", "CLAIM"]
Status = Literal[
    "CLASSIFIED", "UNKNOWN", "NOT_A_RULE", "ALLOWED",
    "SPLIT_REQUIRED", "QUALITY_ONLY", "COLLISION"
]

@dataclass
class RuleInput:
    rule_id: str
    rule_text: str
    condition: str
    rule_nature: Optional[str]          # prohibition/mandate/disclosure/substantiation/recommendation
    jurisdiction: Optional[str]
    topic: Optional[str]
    subcategory_original: Optional[str]
    product: Optional[dict]             # {model, sku, market, spec_version, effective_date}
    content: dict                       # {text, media:[{type,path,timecode}], surfaces:[...]}
    evidence: dict                      # {sources, specs, auth_docs, platform_policies, test_reports}
    context: dict                       # {platform, placement, format, region,
                                        #  product_category, asset_type, submission_field}
    annotations: dict = field(default_factory=dict)

@dataclass
class Hit:
    condition_id: str                   # CHN1..CLM9
    predicate_id: str                   # 原子谓词编号；同一谓词不能同时产生两个轴
    evidence_refs: list                 # 指向 rule_text/来源/规格/授权/媒体时间码
    reason: str

@dataclass
class Result:
    status: Status
    primary: Optional[Axis]
    secondary: Optional[Axis]
    rule_nature: Optional[str]
    jurisdiction: Optional[str]
    severity: Optional[int]             # 1..5；0 仅用于 NOT_A_RULE/ALLOWED
    quality_tag: list[str]
    topic: str
    confidence: Literal["high", "medium", "low"]
    matched_condition: Optional[str]
    unknown_code: Optional[str]
    reasons: list[str]
    atoms: list = field(default_factory=list)   # SPLIT_REQUIRED 时返回
```

### 2.2 主伪码

```python
AXES = ("CHAN", "RIGHT", "SCENE", "DISC", "BRAND", "FACT", "CLAIM")

def classify(rule: RuleInput) -> Result:
    r = normalize(rule)                       # HTML 反转义、trim、统一全半角、去 BOM

    # ---------- 阶段 0：预处理（先于七轴） ----------
    if r.is_empty or r.is_extraction_noise:
        return result(status="NOT_A_RULE", reason="P0_NOISE")

    if r.is_whitelist or r.is_allowed_expression:
        return result(status="ALLOWED", reason="P1_ALLOWED")

    if r.is_aggregate or r.declares_multiple_rewrite_groups:
        atoms = split_aggregate(r)            # 按“N 条/N 组改写/等”拆
        return result(status="SPLIT_REQUIRED",
                      atoms=[classify_atom(a) for a in atoms],
                      reason="P2_AGGREGATE")

    atoms = split_predicates(r)               # 按谓词/对象/动作拆原子
    if len(atoms) > 1:
        return result(status="SPLIT_REQUIRED",
                      atoms=[classify_atom(a) for a in atoms],
                      reason="P3_MULTI_PREDICATE")

    return classify_atom(atoms[0])


def classify_atom(a) -> Result:
    # ---------- 阶段 1：七步判定，首次命中即 primary ----------
    hits = {}
    for axis in AXES:
        h = HIT[axis](a)
        if h is not None:
            hits[axis] = h

    primary = next((ax for ax in AXES if ax in hits), None)
    if primary is None:
        return unknown("U9", "七轴均未命中；是规范缺口，不是通过")

    # ---------- 阶段 2：secondary ----------
    sec = []
    for ax in AXES:
        if ax == primary or ax not in hits:
            continue
        state = independent_predicate(a, primary, ax)
        if state == "SAME_PREDICATE":
            return result(status="COLLISION",
                          primary=primary,
                          matched_condition=hits[primary].condition_id,
                          reason=f"{primary} 与 {ax} 由同一谓词触发；交 §3 分界测试裁决")
        if state == "INDEPENDENT":
            sec.append(ax)

    if len(sec) > 1:
        return result(status="SPLIT_REQUIRED",
                      atoms=split_by_axis(a, [primary] + sec),
                      reason="P4_MULTI_SECONDARY")

    secondary = sec[0] if sec else None

    # ---------- 阶段 3：字段推导 ----------
    nature = read_nature(a)                   # 只读，不推断
    if nature is None:
        return unknown("U7", "rule_nature 缺失")
    if nature not in {"prohibition","mandate","disclosure","substantiation","recommendation"}:
        return unknown("U7", f"rule_nature 非法值：{nature}")

    jur = normalize_jurisdiction(a)
    if jur == "UNKNOWN":
        return unknown("U7", "jurisdiction 缺失或无法判定")
    if jur == "MULTI":
        return result(status="SPLIT_REQUIRED",
                      atoms=split_by_country(a),
                      reason="P5_MULTI_COUNTRY")

    severity = derive_severity(primary, nature, impact_surface(a), repeat_count(a))
    quality = derive_quality_tags(a) if is_form_only(a) else []
    topic = a.topic or a.subcategory_original or ""
    conf = derive_confidence(a, primary, hits[primary], secondary, nature, jur)

    return result(status="CLASSIFIED",
                  primary=primary,
                  secondary=secondary,
                  rule_nature=nature,
                  jurisdiction=jur,
                  severity=severity,
                  quality_tag=quality,
                  topic=topic,
                  confidence=conf,
                  matched_condition=hits[primary].condition_id,
                  reasons=[hits[primary].reason])


def independent_predicate(atom, primary: Axis, other: Axis) -> str:
    hp, ho = HIT[primary](atom), HIT[other](atom)
    if hp.predicate_id == ho.predicate_id:
        return "SAME_PREDICATE"
    rest = remove_predicate(atom, hp.predicate_id)
    return "INDEPENDENT" if HIT[other](rest) is not None else "NOT_INDEPENDENT"
```

**实现约束：**

- `HIT[axis]` 必须是纯函数，不得写文件、不得改状态；同一输入两次运行输出必须逐字节相同。
- `HIT[axis]` 缺少该轴必需输入时只能返回 `None` 或抛 `MissingInput(field)`；不得“凭经验”命中。
- `primary` 只由 `AXES` 顺序决定；`secondary` 只允许一个，且必须与 primary 轴不同、谓词不同。
- 同一谓词同时命中两轴时返回 `COLLISION`，不允许静默选一个；`COLLISION` 在发布门槛必须为 0。
- `SPLIT_REQUIRED` 是合法中间态，不是最终分类；拆出的每个原子规则仍需独立跑 `classify_atom`。
- `EDITORIAL` 不是 primary 值：形式问题返回 `status="QUALITY_ONLY"`、`primary=None`、`quality_tag=[...]`。

### 2.3 七个判定函数的签名与返回

```python
def hit_chan(a) -> Optional[Hit]:
    """CHN1–CHN6。必需输入：context.platform/placement/format/region/
    product_category/asset_type/submission_field + 平台政策/法律原文。
    缺任一必需字段 -> None（由上层转 UNKNOWN U7 或渠道队列）。"""

def hit_right(a) -> Optional[Hit]:
    """RGT1–RGT7。必需输入：可识别主体、使用方式、授权/同意状态、
    AI 生成记录、商标授权、核查记录。授权状态未知 -> UNKNOWN，不命中。"""

def hit_scene(a) -> Optional[Hit]:
    """SCN1–SCN8。必需输入：动作四元组（谁/对谁/环境/参数）、
    媒体（图片/视频/时间码）或分步图示、安全边界来源。
    P0 类别名规则（SCN7）不要求参数；无媒体 -> NOT_APPLICABLE。"""

def hit_disc(a) -> Optional[Hit]:
    """DSC1–DSC10。必需输入：可逐字写出的受众信息元素 X、
    全载体检索记录（正文/图片 OCR/音频转写/视频音轨/包装/落地页）。
    无法指认 X -> None（DSC8 返回 NOT_DISC）。"""

def hit_brand(a) -> Optional[Hit]:
    """BRD0–BRD9。必需输入：品牌语调规范/修订基线、完整上下文、
    活动真实条款、竞品指向。缺基线 -> UNKNOWN，不硬判。"""

def hit_fact(a) -> Optional[Hit]:
    """FCT1–FCT9。必需输入：可判真假谓词、目标型号规格/指南原文/
    公开事实、检索范围。缺来源但无相反结论 -> UNKNOWN，不判违规。"""

def hit_claim(a) -> Optional[Hit]:
    """CLM1–CLM9。必需输入：断言强度与对象、证据材料（报告/认证/
    对比数据/授权）、四匹配字段（存在/主体/口径/范围）。
    材料未提供 -> UNKNOWN，不是通过。"""
```

### 2.4 secondary 的填写规则

`secondary` 只在以下条件全部成立时填写：

1. 同一原子规则中存在**第二个独立谓词/对象/动作**；
2. 删除 primary 谓词后，该原子规则仍然独立构成另一轴的违规；
3. 两个谓词不是同一句话的同一构成要件（否则返回 `COLLISION`）；
4. 只填一个 secondary；出现两个及以上独立 secondaries，返回 `SPLIT_REQUIRED`。

示例：`r-c515e503185d5234` 的 “mimics baby” 是产品机制配置（FACT FCT2），“more milk / faster letdown” 是效果承诺（CLAIM CLM1/CLM6），两个谓词独立，故 FACT primary + CLAIM secondary。`r-0823b2d08a7e4ec2` 的 “10x better” 是缺数据的比较（CLAIM CLM2），“完胜/秒杀/碾压”是贬损表达（BRAND BRD5），拆成两条后各有一个 primary；若暂不拆，BRAND primary + CLAIM secondary，且 secondary 不得写成 BRAND 自身。

### 2.5 confidence 的降级规则

| 级别 | 条件 |
|---|---|
| high | 所有必需输入齐全；命中条件有直接原文/规格/授权指针；规则不是边界/触发词/聚合；辖区唯一 |
| medium | 缺少一个非关键字段但已记录默认假设；或命中依赖词表/边界示例；或规则是触发词清单/边界条款；或辖区由正文推断 |
| low | 规则是聚合体代表、证据材料未提供、辖区/型号/版本缺失、命中依赖 fallback C8、或任何 UNKNOWN |
| UNKNOWN | 任何 unknown code；`confidence` 固定 low |

`confidence` 不是概率，不参与 severity 计算。`confidence=low` 的规则必须人工终审；`confidence=medium` 的规则必须抽检。

### 2.6 UNKNOWN 的返回条件

| code | 触发条件 | 处置 |
|---|---|---|
| U1 | 权威来源之间结论冲突，且规则要求审查员替读者选一个真相 | 转人工；若规则要求披露冲突 → DISC DSC2 |
| U2 | 产品型号/批次/固件/版本/市场不明，无法把参数对到具体配置 | 默认按规则声明的品线/当前型号；仅当规则引用批次/固件时才要求 |
| U3 | 命题指代不明、原文缺失、表格错位、需还原上下文 | 转人工；不得硬判 |
| U4 | 句子是价值判断/主观体验/比喻/纯情绪，没有可判真假谓词 | 转 BRAND/EDITORIAL 或人工，不归 FACT |
| U5 | 只能证明“证据不足/未证实”，指不出任何权威来源或规格与之矛盾 | 转医学/产品审校；不自动判违规 |
| U6 | 涉及未公开产品路线图、临床数据或内部测试 | 转人工；证据集不完整 |
| U7 | `rule_nature` / `jurisdiction` / 渠道元数据缺失或非法 | 补齐字段；缺渠道元数据进独立渠道队列 |
| U8 | 需要画面/音频/版式/渲染才能判形式，但输入只有文本/元数据 | 区分存在性与形式；存在性先查，形式缺素材标 NOT_APPLICABLE 并请求素材 |
| U9 | 七轴均未命中且不属于任何预处理桶 | 规范缺口，必须登记新条件或新桶，不许放行 |
| U10 | 同一谓词同时命中两轴（COLLISION） | 交 §3 分界测试裁决；发布门槛为 0 |
| U11 | 规则归类所用模型不可用（未注入 llm 客户端 / 调用失败 / 返回不合契约） | **不得回退到关键词猜测**；返回 UNKNOWN 并报缺口。回退猜测会把「未测」变成「已判」，正是本规范要防的形态 |

**UNKNOWN 不是通过，也不是违规。** 退出码/状态必须与 CLASSIFIED、NOT_A_RULE、ALLOWED 明显不同；报告里不得写“没问题”。

### 2.7 状态优先级（状态之间也会冲突，必须定序）

同一条规则可能同时满足多个非 CLASSIFIED 状态。按下列**严格优先级**，命中即返回，不再往下判：

| 优先级 | 状态 | 判据 | 为什么在这个位置 |
|---:|---|---|---|
| 1 | `NOT_A_RULE`（噪声） | 空行、表头残留、纯引用、抽取残片 | 非规则不应进入任何后续判定 |
| 2 | `ALLOWED` | 白名单表达、安全词 | 明确允许的表达不再判 |
| 3 | **`SPLIT_REQUIRED`** | `needs_split=true`，或正文自述「N 条/N 组改写」 | **必须高于 NOT_A_RULE**：一个 246 组的聚合体不是「非规则」，是「还没拆开的规则集合」。判成 NOT_A_RULE 会把它永久丢掉 |
| 4 | `COLLISION` | 同一谓词命中两轴 | 交 §3 分界测试，不许静默选一个 |
| 5 | `UNKNOWN` | 命中 U1–U10 | 未测不是通过 |
| 6 | `QUALITY_ONLY` | `is_editorial(rule)=true` | 见 §2.8 |
| 7 | `CLASSIFIED` | 七轴之一 | 正常结果 |

**实测依据**：`r-8380b74f7d98d063`（246 组聚合体）同时满足 `needs_split` 与 `NOT_A_RULE`（其正文只剩「未归类原因」汇总）。按本表返回 `SPLIT_REQUIRED`；若按 `NOT_A_RULE` 处理，372 组改写会被一次性丢弃。

### 2.8 `is_editorial()` 是独立判定，不是七轴之一

**问题实测**：27 条 EDITORIAL 中有 **18 条不在「内容形式与表达规范」子类**（散在哺乳、孕期、产后等子类）。用 `classify_rule` 的 primary 判 EDITORIAL 只能命中 9/27；放宽词表会把大量 FACT/DISC 误判成 EDITORIAL。

**根因**：编辑质量与审查轴**正交**。一条规则可以既要求改错别字、又要求补充医学事实。把 EDITORIAL 塞进 primary 等于强迫二选一。

**规则**：`is_editorial(rule)` 是独立纯函数，只回答一个问题——

> **这条规则的修复动作是否仅涉及形式，不涉及任何事实、证据、披露或渠道？**

```python
def is_editorial(rule) -> bool:
    """只判形式。以下全部成立才返回 True：
    1. 修复动作 ∈ {改错别字, 改标点, 统一术语, 统一格式, 改引用格式, 调整排版,
                    调整配图位置, 改标题层级, 提升可读性, 本地化措辞}
    2. 不涉及：新增/修改任何事实陈述、补充任何证据、新增任何披露义务、
               改变任何渠道准入、改变任何品牌立场
    """
```

**与 primary 的关系**：
- `is_editorial=True` 且规则不涉及任何轴 → `status=QUALITY_ONLY`，`primary=None`，`quality_tag=[...]`
- `is_editorial=True` 但规则同时要求改事实 → `primary=FACT`，**`quality_tag` 仍记录形式部分**（两者并存，不互斥）
- 原表 27 条 EDITORIAL 是先验标注（按「整体印象」标），本函数逐条重判，允许与原标注不同——**不一致的条目要列出，不许静默对齐**

## 3. 七轴严格定义

### 3.1 CHAN 渠道控制

**定义。** CHAN 审查“这条内容能不能在这个平台/渠道、目标地区、版位与形式、提交字段、平台授权素材下投放”。判定只依赖渠道元数据和可引用的平台政策/法律原文，不评价文案真假、证据强弱、语气或消费者是否被充分告知。判别式：**同一文案换一个平台/地区/版位/提交方式就从合规变违规，且原因来自渠道规则 → CHAN**。

**判定条件（可执行）：**

| ID | 条件（when） | 返回 |
|---|---|---|
| CHN1 | `rule.regulated_object ∈ {channel_access, placement, ad_format, submission_field, platform_asset}` 且规则文本点名至少一个 {品类, 地区, 版位, 形式, 提交字段, 平台自有素材} | 命中 CHAN |
| CHN2 | `ad.product_category` 属于规则在 `target_region/platform` 明确禁止投放的品类（如 Austria 全渠道婴配粉、Singapore 口香糖、UK HFSS 非 STV 例外、临床试验招募、注射器/专业用医疗器械） | 命中 CHAN |
| CHN3 | `ad.placement` 属于规则禁止的版位（如 sponsorship/takeover）或 `ad.format` 缺少规则要求的字段（如 headless API 的 description） | 命中 CHAN |
| CHN4 | `ad.asset` 未经授权使用**平台自有**标识/榜单/logo（Amazon's Choice、Best Seller 排名、篡改的 Amazon logo） | 命中 CHAN |
| CHN5 | 同一文案在渠道 A 合规、渠道 B 违规，差异仅来自 platform/region/placement/format 规则 | 离线规则库一致性检查；单条审查不单独求值 |
| CHN6 | 规则只有“必须遵守所有适用法律/平台政策”或等价泛化条款，无法定位到具体品类/版位/地区/字段/授权素材 | 不命中 CHAN；返回 NOT_A_RULE 或挂起 |

**不属于本轴：**

- 文案内部事实是否属实（FACT）；例如“Austria 是否真的禁止婴配粉广告”这一陈述本身是否准确。
- 对外断言是否有测试/来源支撑（CLAIM）。
- 消费者必须看到的披露/标注/免责（DISC）。
- 人格/肖像/AI 生成合法性（RIGHT）。
- 画面中的危险行为示范（SCENE）。
- 品牌调性/口号/情绪话术/竞品贬低（BRAND）。
- 编辑质量（EDITORIAL）。
- 平台政策中的**内容禁令/立场要求**（如“不得鼓励以配方奶替代母乳”）：即使来源是平台政策，只要判定点是内容立场而非渠道元数据，归 BRAND BRD4；平台来源只改 `jurisdiction=PLATFORM`，不改主轴。

**与邻轴的分界测试：**

| 邻轴 | 测试 | 例 |
|---|---|---|
| DISC | 删掉全部消费者可见文字后义务仍存在（版位/字段/品类/授权素材）→ CHAN；义务随之消失（要展示给消费者的披露）→ DISC | 付费合作内容不得出现在 sponsorship 版位 → CHAN；付费合作必须标注 #ad → DISC |
| FACT | 同一事实用于决定投放准入 → CHAN；用于核查文章陈述是否准确 → FACT | “Austria 禁止婴配粉广告”作为准入规则 → CHAN；作为文章法律事实被核查 → FACT |
| BRAND | 结论是“平台拒登/下架”且由渠道元数据驱动 → CHAN；结论是“品牌不该这么说” → BRAND | 平台禁止该品类 → CHAN；平台政策说“不得 discouraging breastfeeding” → BRAND |
| RIGHT | 平台自有标识/榜单/平台 logo → CHAN；平台外第三方商标/标识 → RIGHT | Amazon's Choice → CHAN；竞品 logo 改色做对比 → RIGHT |

**复核人。** 渠道运营（平台政策负责人）复核；分地区禁令由合规法务二次复核；平台标识/授权素材由对应平台账号管理员复核。

**证据要求。** 必须给出：① 平台政策或法律条款原文（文档名 + 条款号 + 版本/生效日期）；② 本次广告的渠道元数据（platform、placement/format、target_region、product_category、asset_type、submission_field）；③ 品类禁令还需产品品类与目标地区的对应关系。缺①或②不得判 CHAN，落 UNKNOWN U7；泛化条款落 NOT_A_RULE。

### 3.2 RIGHT 权利控制

**定义。** RIGHT 审查“内容使用可识别真人、未成年人形象、AI 合成人物/事件、第三方商标/标识、自然人隐私信息时，授权链是否成立”。判定单元是（可识别主体、使用方式、授权/标识证据）三元组。RIGHT 只判授权链；不判推荐内容是否真实（CLAIM）、披露是否显著（DISC）、平台是否允许（CHAN）、动作是否安全（SCENE）。AI 标识的**存在性/显著性/位置**归 DISC；只有合成的是可识别真人/真实事件且未授权时，RIGHT 才作 primary。

**判定条件（可执行）：**

| ID | 条件（when） | 返回 |
|---|---|---|
| RGT1 | 内容使用可识别真人的姓名、肖像、声音或形象（专家、医生、用户、员工、达人）明示或暗示其推荐、使用或合作，且按证据要求完成核查后仍无可核验的授权证据 | 命中 RIGHT |
| RGT2 | 内容出现未成年人的可识别面部、身体、姓名、学校、住址、病历或联系方式（出镜或隐私暴露）；监护人同意不默认豁免，是否可豁免按适用法域与平台规则确认 | 命中 RIGHT |
| RGT3 | 内容含 AI 生成/深度合成的人像、声音或真实事件（换脸、声音克隆、虚拟人、生成式人物），可能使受众误认为真实人物/真实事件，且未按适用法域取得授权/标识；若合成对象不是可识别真人/真实事件，不命中 RIGHT，转 DISC DSC5 | 命中 RIGHT |
| RGT4 | 内容使用**平台外第三方**商标、logo、认证标志，存在未授权、篡改、仿冒或暗示背书。三类可判：① 相同/混淆性相似商标使用；② 对标识的篡改/去除；③ 明示或可逐字引用的背书陈述。暗示只保留可列举场景（并列展示 + 推荐语；竞品 logo + 本品胜出文案） | 命中 RIGHT |
| RGT5 | 内容披露自然人的隐私信息（联系方式、住址、身份证号、病历、健康数据、精确位置）且无本人或监护人同意 | 命中 RIGHT |
| RGT6 | 内容把 AI 合成人物当作真实用户/真实专家作证（虚拟人冒充真人证言），无论是否标识 | 命中 RIGHT |
| RGT7 | 授权状态查不到，但已向宣称方发起核验请求并留痕；请求未到期 | 不命中 RIGHT，返回 UNKNOWN（带 P0 标记）；请求到期仍无授权且规则为 P0 → 命中 RIGHT |
| RGT8 | 仅出现公开文献作者、政府机构名称、虚构角色、无署名的群体称谓（如“100+ experts”但无姓名/面部/声音） | 不命中 RIGHT；转 CLAIM CLM4 |

**不属于本轴：**

- 泛指“医生推荐/专家推荐”但没有可识别真人 → CLAIM。
- 推荐内容是否真实、是否有依据 → CLAIM。
- 披露是否清晰、显著、及时 → DISC。
- 平台准入、版位、素材规格、平台站内榜单标识 → CHAN。
- 品牌调性、口号、竞品贬低 → BRAND。
- 事实真伪、参数准确、知识正确 → FACT。
- 排版、配图、标题、引用格式 → EDITORIAL。
- “查不到授权”不等于“没有授权”；判无授权必须有核查记录，否则 UNKNOWN。

**与邻轴的分界测试：**

| 邻轴 | 测试 | 例 |
|---|---|---|
| CHAN | 平台站内使用平台榜单/标识 → CHAN；平台外未授权使用他人商标/标识 → RIGHT | Amazon's Choice 站内素材 → CHAN；独立站把竞品 logo 改色做对比 → RIGHT |
| SCENE | 争点是“使用这个孩子的形象要不要监护人同意/是否属于未成年人出镜” → RIGHT；争点是“孩子所处动作/环境是否安全” → SCENE；同时成立 RIGHT 先、SCENE 记 secondary | 宝宝正脸清晰 → RIGHT；只拍座椅/局部且宝宝未扣安全座椅 → SCENE |
| DISC | 合成的是可识别真人身份/事件 → RIGHT（标识是补救措施）；纯示意图/动画无可识别真人 → DISC（AI 标识义务） | 换脸/克隆真实妈妈声音 → RIGHT；纯 AI 动画示意图 → DISC |
| CLAIM | 争“有没有授权用这个人的姓名/肖像” → RIGHT；争“推荐是否真实、有无依据” → CLAIM | 专家确有其人但未授权署名 → RIGHT；专家已授权但从未推荐 → CLAIM |

**复核人。** 内容合规审查员初判；肖像、隐私、AI、未成年人条目必须由法务复核；P0 红线由合规负责人签字。

**证据要求。** 判 RIGHT 必须给出：① 可识别主体（姓名/面部/声音/商标的具体位置与指向）；② 授权或同意证据（肖像/姓名使用授权书、监护人同意、AI 生成记录与工具链、商标授权）；③ 若判“无授权/未标识”，必须附核查记录（向谁核、何时核、核了什么）。②无法取得 → UNKNOWN，不是“默认无授权”；但 P0 规则在核验请求到期后仍无授权 → 判 RIGHT，不是 UNKNOWN。

### 3.3 SCENE 场景控制

**定义。** SCENE 审查“内容所呈现（画面/视频/图文步骤）、演示或教导的物理动作与场景，按内容照做是否会伤害人”。判定单元是动作四元组（谁做、对谁做、在什么环境、用什么参数与约束）。只判动作及其参数是否越界，不判文字是否符合文献、也不判是否加了免责声明。可执行判据：**把内容里的数字与表述全部改对之后，动作仍然会造成或纵容身体伤害 → SCENE；改对数字或补一句警示即可消除风险 → FACT 或 DISC。**

**判定条件（可执行）：**

| ID | 条件（when） | 返回 |
|---|---|---|
| SCN1 | 内容以教程、示范、挑战或使用步骤的形式呈现一个可被模仿的物理动作，该动作可导致跌落、烫伤、窒息、溺水、中毒、触电、感染、碾压或交通事故之一；按伤害类型缺少标准约束清单中的任一项；且补齐标准约束后动作本身仍越界 | 命中 SCENE |
| SCN2 | 画面、视频或分步图示把未成年人/婴幼儿置于可预见的危险布置：独留车内、未使用安全座椅、无人看护的高处/成人胸前/床边、不安全睡姿、可触及热水/药品/小件/电器 | 命中 SCENE |
| SCN3 | 内容给出的产品使用参数确定越出安全边界（直接冰敷、明火或高温加热、超时/超档使用、尖锐部件未固定），而不是仅仅缺少参数说明 | 命中 SCENE |
| SCN4 | 内容把一个仅对特定人群禁忌的动作作为**无人群限定的普适推荐**，且修复必须改变推荐/删除动作（不是只补一句禁忌提示） | 命中 SCENE |
| SCN5 | 画面或步骤图示的场景布置本身构成风险（门栏未固定、婴儿与成人同床侧躺、安全座椅未约束、热源紧邻婴儿床） | 命中 SCENE |
| SCN6 | 内容以第一人称/近距离镜头演示危险动作，并配明确鼓励语（你也可以试试/一起来/挑战），且无警示标注 | 命中 SCENE；提高 severity |
| SCN7 | 规则是 P0 类别名规则（危险行为示范、儿童乘车安全/安全座椅/独留车内），即使规则正文没有具体动作/参数 | 命中 SCENE；无媒体 → NOT_APPLICABLE + 人工 P0 复核，不落 UNKNOWN |
| SCN8 | 动作保留，只增加温度/时长/部位/人群限制/警示/免责 | 不命中 SCENE；转 DISC DSC6 |

**标准约束清单（按伤害类型，SCN1 用）：**

| 伤害类型 | 必填约束（缺一即命中） |
|---|---|
| 跌落 | 护栏/围挡、成人看护、高度限制、防滑/固定 |
| 烫伤 | 温度上限、时长、距离、隔热层、避开部位 |
| 窒息 | 小件尺寸、睡姿、床面硬度、看护人、远离塑料袋/绳索 |
| 溺水 | 水深、成人一臂距离、救生设备、不得独留 |
| 中毒 | 物品存放、剂量、通风、就医指征 |
| 触电 | 电源隔离、防水、儿童不可触及 |
| 感染 | 消毒、一次性用品、伤口隔离 |
| 碾压/交通 | 安全座椅/约束、车内独留、倒车视线、道路环境 |

**不属于本轴：**

- 文字、数字或指南立场与文献不符，但动作本身不危险 → FACT。
- 动作本身合规，只缺警示语、参数说明、免责声明或风险提示 → DISC。
- 平台对素材形式、版位、文件规格的限制 → CHAN。
- 宣称有无依据、效果是否可证明 → CLAIM。
- 品牌调性、口号、竞品贬低 → BRAND。
- 排版、配图、标题、引用格式 → EDITORIAL。
- 不能因出现“安全/危险/注意”等词就判 SCENE；必须指得出具体动作/场景、伤害类型与触发条件。
- 不能把“内容提到某个风险”当成“内容示范了该风险”。

**与邻轴的分界测试：**

| 邻轴 | 测试 | 例 |
|---|---|---|
| FACT | 把数字/表述改对后动作还危险吗？还危险 → SCENE；改对即解决 → FACT | 竖抱适合 2–3 个月：月龄与文献不符 → FACT；视频中 3 个月宝宝竖抱无人托头颈 → SCENE |
| DISC | 要改/删动作本身 → SCENE；动作保留、只补警示/参数/免责 → DISC | 加热垫覆盖乳房 5 分钟：只补温度/部位/禁忌 → DISC；判定“直接冰袋”不可做、必须换温和方式 → SCENE |
| RIGHT | 争点是使用未成年人形象要不要同意 → RIGHT；争点是孩子所处动作/环境是否安全 → SCENE | 宝宝正脸清晰 → RIGHT；宝宝未扣安全座椅 → SCENE |

**复核人。** 内容合规审查员初判；母婴/婴幼儿安全、产品使用类条目由产品安全负责人 + 医学顾问复核；P0 红线由合规负责人签字。

**证据要求。** 判 SCENE 必须给出：① 具体动作/场景原文或素材时间点（谁、对谁、在什么环境、什么参数）；② 越界判断所依据的安全边界来源（产品说明书、AAP/ACOG/CPSC/EN 标准等，带版本或日期）；③ 伤害类型与触发条件。判“安全”同样要给边界依据；给不出 → UNKNOWN，不是通过。

### 3.4 DISC 披露控制

**定义。** DISC 审查“必须出现的受众可见信息元素 X 是否出现、是否完整、是否以规定形式出现”。不审查 X 背后的主张是否真实、是否有依据，也不审查行为指导是否安全。判定分三步：① 指认 X（免责声明/限定条件/重大风险/利益关系/身份资质/法定标识），且 X 能被逐字写出；② 在最终受众可见载体（正文、图片、音频、视频、包装、落地页）上检查存在性与完整性；③ 若规则同时规定模态/位置/时长/字号/音量，再检查形式合规。

**判定条件（可执行）：**

| ID | 条件（when） | 返回 |
|---|---|---|
| DSC1 | 规则谓词是 include / disclose / accompany / label / mark / state / communicate（中文：需明确/应说明/必须标注/加注/提示/披露/告知/**补充**，其中「补充」须先过 DSC11–DSC12），且宾语 X 是受众可见、可逐字写出的信息串；显式排除 RIGHT 已接管的 AI 深度合成标识/未成年人身份标识 | 命中 DISC |
| DSC2 | 规则允许 claim C 保留，但要求限定 Q 同时出现（Q = 免责声明、适用条件、地区差异、证据局限、个体差异），且 Q 可逐字写出；Q 的最小完整性 = 对象/条件/期限/风险/证据局限至少一项，且与 C 同载体、同语言、同显著度 | 命中 DISC；C 的证据问题记 secondary=CLAIM |
| DSC3 | 规则要求披露说话人与品牌之间的关系或身份：付费/赞助/雇佣/职务/股权/专家资质/利益冲突（COI） | 命中 DISC；关系真实性存疑时 secondary=CLAIM |
| DSC4 | 规则规定某个已被要求披露的信息的模态/位置/停留时长/字号/对比度/音量/语速；存在性与形式分开检查 | 命中 DISC；缺渲染素材 → NOT_APPLICABLE + 请求素材 |
| DSC5 | 法规要求包装或素材上出现法定标识、logo、认证标记，且该品类在该渠道允许销售 | 命中 DISC |
| DSC6 | 内容作出明示或暗示的安全/健康表述，规则要求同时说明重大风险或局限，而规则并不禁止该表述本身 | 命中 DISC |
| DSC7 | 规则只要求向监管机构申报/备案（notify FDA、登记、提交材料），不产生任何受众可见信息元素 | 不命中 DISC；NOT_A_RULE/运营义务 |
| DSC8 | 无法指认任何必须出现的受众信息元素 X，或去掉 X 后基础事实、行为指导、证据、语气、渠道问题仍然独立成立 | 不命中 DISC；按顺序落到下一轴 |
| DSC9 | DISC 与 BRAND/FACT/CLAIM 同时可命中，且 CHAN/RIGHT/SCENE 均未命中 | 归 DISC primary，其余轴记 secondary |
| DSC10 | 规则纠正的是临床行动阈值/就医时点（如“疼痛超过两周”→“持续不缓解”、“胎动 2 小时少于 6 次”） | 不命中 DISC；转 FACT FCT3 或 SCENE |
| DSC11 | 修订动作写作「补充说明／补充：X」，而 X 是**主命题缺失的事实成分**（数值、口径、适用边界、必要步骤），补上之后原句才成为一句完整且正确的陈述；X 不能单独成句而不改变原命题真值 | 不命中 DISC；转 FACT FCT10 |
| DSC12 | 修订动作写作「补充／补一句／补充提示」，X 是**面向读者的一句独立告知**（风险、禁忌、就医提示、免责、身份关系、法定标识），去掉 X 原命题真值不变，只是受众少知道一件事 | 命中 DISC（DSC1 的谓词表因此包含「补充」） |

**不属于本轴：**

- 基础陈述本身不准确、不完整或过时（就医指征、剂量、时间窗、产检频率、胎动阈值）→ FACT。
- 修订动作是「补充说明／补充：X」而 X 是主命题缺失的事实成分 → FACT FCT10，不按「补充」这个谓词直接判 DISC（见 DSC11–DSC12）。
- 行为或操作指导本身不安全（热敷温度、深蹲禁忌、竖抱月龄、危险动作示范）→ SCENE。
- 主张缺少 competent and reliable scientific evidence、效果百分比/销量/评分无出处 → CLAIM。
- 单纯为证明数据真实性而要求标注参考文献 → CLAIM 的 substantiation；只有规则明确要求向受众说明证据局限或来源时才归 DISC。
- 语气、情绪操控、倒计时焦虑、竞品贬低、公共卫生话语框架 → BRAND。
- 品类/版位/地区投放禁令、素材提交字段必填 → CHAN。
- 肖像/隐私/未成年人出镜/AI 深度合成标识的合法性 → RIGHT。
- 向监管机构申报/备案、内部台账、合同留存 → 不是受众披露。
- 把“补充风险提示/建议就医”这个修订动作本身当成 DISC 的充分条件：必须先问基础陈述是否已经不安全或不准确。
- 披露文本存在但主张仍无依据：不得因“已披露”就判合规，须把证据问题记 secondary=CLAIM。

**与邻轴的分界测试：**

| 邻轴 | 测试 | 例 |
|---|---|---|
| SCENE | 去掉这条要求后，读者照做是否仍然安全、准确？否 → SCENE；是，只是少了一句法定/政策要求的告知 → DISC | 热敷补“温度不可过高、避开乳头乳晕、疑似乳腺炎不要热敷” → 动作保留，DISC；直接冰袋这个动作本身不可做 → SCENE |
| BRAND | 补一条事实性披露（付费合作/利益关系/限定语）即可合规 → DISC；必须改写语气、情绪框架或品牌立场才合规 → BRAND | 付费达人缺 Ad/Paid partnership → DISC；无付费关系的倒计时焦虑 → BRAND |
| FACT | 缺陷是命题本身真假或是否适用于该地区 → FACT；命题为真但规则额外要求限定/免责/风险告知 → DISC | 糖耐空腹写成全球统一 → FACT；已限定地区但要求写出筛查方案差异 → DISC |
| CHAN | 该品类/版位在该市场是否被允许 → CHAN；允许但素材必须带标识/免责/披露 → DISC | 有机产品在巴西若法律禁止广告 → CHAN；允许销售但包装必须出现有机 logo → DISC |
| CLAIM | 问题是“主张有没有依据” → CLAIM；问题是“关系/身份/利益有没有告诉受众” → DISC；证据缺口触发 → CLAIM primary、DISC secondary | ibclc-recommended：无真实推荐 → CLAIM；有真实合作但未披露 COI → DISC |

**复核人。** 规则治理 Owner 复核本轴归属与词表；US/FTC、EU、BR、CN 等辖区条款由对应法务/合规复核；DISC 与 SCENE/BRAND/CLAIM 的边界样本由两名标注员背靠背判定，不一致交 Owner 仲裁。

**证据要求。** 判定成立至少要有四类证据：① 规则证据：rule_id、jurisdiction、rule_nature=disclosure/mandate，以及被触发条款的逐字原文；② 触发证据：内容中触发披露义务的原文/画面/音频（含时间码或坐标）；③ 缺失或形式证据：对 X 的存在性检查结果——未找到时须列出已检索的全部受众可见表面（正文全文、图片 OCR、音频转写、视频音轨与画面、包装/落地页）及检索串；形式不合格时须给出字号、对比度、停留时长、音量/语速等可复核读数；④ 关系/标识证据：付费合同、雇佣或职务记录、专家资质与 COI 声明、包装设计稿。否定结论必须满足“所有通道都采过且各自自证活着”：只查正文没查图片或音频，不得判“未披露”，只能落 UNKNOWN；肯定结论须给出披露文本在载体中的具体位置。

### 3.5 BRAND 品牌控制

**定义。** BRAND 管表达层：口号与价值主张、情绪与压力话术、品牌立场/口吻、竞品贬低是否损害品牌调性与品牌关系。判别式：**把文案中每个事实都改为真、每个对外断言都补足证据后，问题仍然存在（仍在制造焦虑、操纵紧迫、立场错位或贬损竞品）→ BRAND。** BRAND 不裁决事实真假（FACT）、证据是否充分（CLAIM）、法定披露是否齐全（DISC）、渠道/版位是否允许（CHAN）；竞品对比若缺陷是“没有数据/没有口径”，归 CLAIM，不因出现“碾压/秒杀”字样就归 BRAND；贬损措辞本身归 BRAND，缺数据记 CLAIM secondary。

**判定条件（可执行）：**

| ID | 条件（when） | 返回 |
|---|---|---|
| BRD0 | 纯口号/价值主张，不承载任何可核查的产品利益（comfort、care、love、your pace 等），且无产品属性指涉 | 命中 BRAND；若口号同时承载可核查产品利益（more milk、7 minutes、22% slimmer），拆出 CLAIM 原子 |
| BRD1 | 把文案中每个事实改为真、每个对外断言补足证据后，内容仍制造/放大焦虑、羞耻、内疚或挫败感以驱动行为 | 命中 BRAND |
| BRD2 | 文案含紧迫/压力触发词（last chance、limited time、final hours、don't miss、act now、hurry、限时、最后机会、手慢无、不买后悔），且促销本身真实存在；缺陷是倒计时/最后机会的话术，不是条款缺失或价格虚假 | 命中 BRAND；缺条款 → DISC primary、BRAND secondary |
| BRD3 | 内容结尾或段落反复进行情绪安抚/负面渲染，超出事实陈述所需，反而强化读者焦虑 | 命中 BRAND |
| BRD4 | 文案事实成立，但立场/框架与品牌声明的价值主张或目标市场公共卫生立场冲突（如把配方奶与母乳并列为等价选项、使用奶粉公司营销口吻） | 命中 BRAND |
| BRD5 | 竞品对比使用贬损性/绝对化语言（碾压、秒杀、垃圾、完胜）；不要求“事实与证据层成立”作为前件 | 命中 BRAND；缺数据/缺口径 → CLAIM secondary |
| BRD6 | 唯一缺陷是错别字、语病、章节结构、术语规范、参考文献或配图，不改变语气/立场/情绪效果 | 不命中 BRAND；只打 quality_tag=EDITORIAL |
| BRD7 | 一条规则同时含品牌话术与功效承诺/事实错误，且两部分各有独立谓词 | 预处理阶段拆原子；每个原子只留一个 primary；≥2 个独立 secondaries → SPLIT_REQUIRED |
| BRD8 | 情绪强度/煽情度超出品牌语调基线（情绪词密度、感叹号、第二人称抒情句超过版本化 rubric 阈值） | 命中 BRAND；无 rubric → UNKNOWN 或仅 quality_tag |
| BRD9 | 既没有品牌语调规范，也没有同一内容线的既有审核基线/修订样例 | 不命中 BRAND；UNKNOWN（治理阻塞，不逐条硬判） |

**不属于本轴：**

- 事实是否属实/参数是否准确/知识是否正确 → FACT。
- 对外断言是否有依据 → CLAIM。
- 竞品对比缺数据/缺口径 → CLAIM（可记 secondary=BRAND）。
- 法定披露/标注/免责/广告标识/活动条款/风险提示 → DISC。
- 渠道准入/版位/素材形式 → CHAN。
- 人格/肖像/AI 合法性 → RIGHT；画面行为安全 → SCENE。
- 纯编辑质量 → quality_tag=EDITORIAL。
- “听起来不够高级”不是 BRAND 的判据；必须有版本化基线或可列举的词表/修订样例。

**与邻轴的分界测试：**

| 邻轴 | 测试 | 例 |
|---|---|---|
| FACT | 先做真实性替换：把每个事实改成真的，问题还在吗？还在（仍制造焦虑/立场错位/贬损）→ BRAND；不在（问题正是事实为假）→ FACT | 配方奶喂养的宝宝同样可以健康成长：医学上不准确 → FACT；事实成立但把它立为小节标题、与母乳喂养参照框架冲突 → BRAND |
| CLAIM | 看缺陷是“没有证据/没有口径”还是“有证据但说法伤人/操纵”：前者 CLAIM；后者 BRAND | 10x better than Medela 无来源 → CLAIM；有完整对比数据仍用“碾压/秒杀” → BRAND |
| DISC | 缺活动条款/日期/免责/广告标识 → DISC；条款齐全但用倒计时制造压力 → BRAND | Hurry, act now, don't miss：缺条款 → DISC；条款齐全 → BRAND |
| EDITORIAL | 看修改理由诉诸什么：结构/术语/参考文献/错别字 → EDITORIAL；读者情绪/品牌立场 → BRAND | 删除“反复”只因术语不精确 → EDITORIAL；理由是避免妈妈挫败感 → BRAND |

**复核人。** 品牌市场负责人 + 内容主编复核；母乳喂养/配方奶立场类加公共卫生或医学顾问；促销话术类由投放运营确认活动真实性（仅用于区分 BRAND/DISC/FACT，不改变主轴）。

**证据要求。** 必须给出：① 品牌语调/价值主张规范（版本号）或目标市场公共卫生立场文件；若两者都没有，则至少要有同一内容线的既有审核基线/修订样例；② 完整上下文（至少前后段或整篇结尾，不能只取一句）；③ 促销类需活动真实条款（日期、折扣、库存）以区分真实紧迫与虚构紧迫；④ 竞品类需指明竞品与完整对比语境。①的规范与替代基线都缺时只能落 UNKNOWN 或 quality_tag=EDITORIAL，不得判 BRAND。

### 3.6 FACT 事实控制

**定义。** FACT 审查“内容中的事实性命题与可核验事实是否一致”，回答三个问题：这条知识是否正确、这个参数/功能是否与产品实际一致、这个使用场景是否有文件支持。只覆盖三类对象：(a) 母婴/健康/护理知识命题（生理、解剖、时间节点、剂量、操作步骤、发育里程碑、储存条件、用药安全等）；(b) 产品客观参数、功能与部件配置（是否具备某功能、mmHg、dB、档位、容量、续航、材质牌号/标准、部件数量、适配结构）；(c) 产品的实际使用场景事实（是否在医院/NICU 使用、有无临床使用文件）。认证/注册/等级/专家背书等资质宣称不在此列，归 CLAIM。判定算法固定四步：① 域判定（知识命题/产品客观事实/使用场景）→ ② 命题抽取（能否写成可判真假的谓词）→ ③ 来源比对（相反来源、规格不符、数值/单位/口径错误、分类/术语错误）→ ④ 先命中先归（与 CLAIM 同时命中时 FACT 优先，但 FACT 侧必须指得出具体矛盾来源或规格；指不出则让位 CLAIM 或落 UNKNOWN）。

**判定条件（可执行）：**

| ID | 条件（when） | 返回 |
|---|---|---|
| FCT1 | 命题 p 属于母婴/健康/护理知识域，且权威来源 s 明确满足以下三类之一：① s 给出相反数值区间（区间比较）；② s 逐字写出相反推荐/禁止；③ s 的适用人群/场景与 p 的适用人群/场景字段不同 | 命中 FACT；必须引用 s 的原文与版本/页码 |
| FCT2 | 命题 p 描述产品客观配置（是否具备某功能、模式/档位、吸力 mmHg、噪声 dB、容量、续航、材质牌号/标准、部件数量、适配结构、是否有某部件），且 p 与目标型号最新规格书/说明书/实测记录/版本清单不一致；只判数值/布尔配置，不判“medical-grade/ultra-quiet/silent”等等级/形容词 | 命中 FACT；按规格书事实改写或删除功能表述 |
| FCT3 | p 含数值、单位、时间窗、频率、剂量、月龄或温度，且与权威来源的可接受区间不一致，或单位/分母/计时口径写错（mg vs mcg、ml vs oz、小时 vs 分钟；per-feed vs per-24h；rinse-off vs leave-on 的暴露时间）；临床行动阈值/就医时点也归本条件 | 命中 FACT；按正确数值与口径改写 |
| FCT4 | p 用错术语或把对象归入错误类别/场景（泌乳 vs 排乳、嗜睡 vs 睡眠、冰袋 vs 蓝冰、爽肤水归为冲洗型、FDA approved vs cleared/registered），且该混淆会改变某个可判真假谓词的真值；若只是命名习惯/可读性，不命中 FACT，转 EDITORIAL | 命中 FACT；统一术语或补适用边界 |
| FCT5 | p 断言产品在医院/NICU/临床场景被实际使用或被采用；需要正面反证：说明书/注册文件明确限定“仅限家庭使用、不用于临床”，或注册范围明确排除医院；仅“查无临床使用文件”不构成违规 | 命中 FACT；删除场景表述或补临床使用文件 |
| FCT6 | p 属于**非产品**知识域，以确定语气陈述因果关系/效果/机制；证据集中没有任何一级来源支持 p，且至少一篇同级来源明确否定 p | 命中 FACT（substantiation 子型）；补直接文献、降级为限定语或删除 |
| FCT7 | p 声称某具名指南作出某推荐/不推荐，而对照该指南原文（指南名、版本、条款/页码）并不存在该推荐；来源沉默不等于相反结论 | 命中 FACT（指南归属误引）；引用原文或删除归属 |
| FCT8 | 知识指令缺少必要步骤/适用条件，导致读者无法执行或会误用；且权威指南把非产品处置 Z 列为一线，内容未提 Z | 命中 FACT（知识完整性/处置缺口）；必须指得出指南与 Z |
| FCT9 | 同一命题有两份同等级来源冲突，规则没有要求披露冲突，且审查员必须替读者选一个真相 | 不命中 FACT；UNKNOWN U1；若规则要求披露冲突/局限 → DISC DSC2 |
| FCT10 | 规则以「补充说明／补充：X」的形式修订，X 是主命题缺失的事实成分（数值、口径、适用边界、必要步骤），补上后原句才成为完整正确陈述；**判定测试**：把 X 拿掉，原句是否为假或不可执行？为真且可执行 → 不是 FACT，回 DSC12 | 命中 FACT（事实不完整）；与 FCT8 的区别：FCT8 要有权威指南指明缺失的处置 Z，FCT10 不需要第三方指南，缺陷由原句自身不自洽证明 |

**不属于本轴：**

- 广告绝对化与最高级用语（maximum/strongest/ultra-quiet/最静音/零噪音等）→ CLAIM，即使事实上不成立也不先用 FACT 处理。
- 产品功效、效果、优越性、零风险、认证/注册/等级/专家背书等对外说服性断言 → CLAIM。
- 品牌调性、口号、情感话术、促销紧迫感、竞品贬损语气 → BRAND。
- 必须披露而未披露、免责/限定/证据局限缺失 → DISC。
- 画面中的行为安全、操作风险、危险动作 → SCENE。
- 人格权、肖像权、隐私、AI 合法性 → RIGHT。
- 渠道准入/形式合规、平台政策 → CHAN。
- 错别字、排版、结构、重复、可读性、引用格式 → EDITORIAL。
- 价值判断、主观体验、比喻、消费者感受（更舒适、更懂你、温柔呵护）——没有可判真假的谓词，不构成 FACT 命题。
- 来源之间的正常口径差异（不同指南范围不同、不同研究结论不一致）——不判事实错误，落 UNKNOWN，不硬凑。
- 仅凭“找不到来源”就判违规——必须能指出相反来源或具体规格不符；否则只能走 FCT6 的明确否定或 UNKNOWN。
- 缺少产品型号/批次/固件版本/适用市场时**不自动** UNKNOWN：默认按规则声明的品线当前型号规格判定；只有规则本身引用批次/固件时才要求对应证据。
- 等级/形容词（medical-grade、ultra-quiet、silent）→ CLAIM，不论事实真假。

**与邻轴的分界测试：**

| 邻轴 | 测试 | 例 |
|---|---|---|
| BRAND | 先做真实性替换：把原句改成完全真实、可举证且中性的同义表述后，违规消失 → FACT/CLAIM；违规仍在（调性/情绪施压/紧迫感/口号框架/竞品贬损）→ BRAND | 配方奶喂养的宝宝同样可以健康成长：医学上不准确 → FACT；事实成立但立为小节标题、以配方奶为对照基准 → BRAND |
| CLAIM | 问“修这句话要改事实，还是补证据？”只需对照权威指南/规格表/公开事实就能判对错 → FACT；命题本身可成立但拿不出相称证据 → CLAIM | mimics baby 与解剖/生理事实不符 → FACT；faster letdown 拿不出本品测试数据 → CLAIM |
| DISC | 缺陷是命题本身真假/是否适用该地区 → FACT；命题为真但规则额外要求限定/免责/风险告知 → DISC | 糖耐空腹写成全球统一 → FACT；已限定地区但要求写筛查差异 → DISC |
| SCENE | 改数字/来源/事实表述 → FACT；改动作/人群限制/操作参数 → SCENE；两者都要改 → 拆条 | 竖抱适合 2–3 个月：月龄与文献不符 → FACT；视频中无人托头颈 → SCENE |

**复核人。** 知识命题：IBCLC 或产科/儿科医师双人复核（涉及用药/成分时加药学审校）；产品参数、功能与使用场景：产品/工程负责人按目标型号规格书与临床使用文件复核；最终归属与签发：内容合规审查负责人。复核不一致即落 UNKNOWN，不硬判。

**证据要求。** 判 FACT 违规必须同时给出四件套：(1) 被质疑的原句与所在位置（文档/段落/字段）；(2) 可援引来源原文摘录 + 版本/日期/页码或 URL——知识命题用指南/系统综述/权威教科书/监管文件，产品事实用目标型号最新规格书/说明书/实测记录/临床使用文件；(3) 一条显式比对，说明原句与来源如何矛盾或不符（数值、单位、时间窗、分类、功能配置、适用场景至少一项对得上）；(4) 受影响对象与范围（产品型号、市场/辖区、人群、版本）。缺 (2) 或 (3) 不得判 FACT；只有“我觉得不对”不构成证据。市场泛化表述（如档位/主流配置）需附抽样清单与日期；同一命题有两份同等级来源冲突时，降级为 UNKNOWN。

### 3.7 CLAIM 宣称控制

**定义。** CLAIM 审查对外宣称的证明责任而非内容真假：句子以品牌/产品/服务为主语，向消费者断言或暗示效果、性能、比较优势、资质等级、排名、专家背书或绝对化地位，且合规判定必须调取证据材料（测试报告、临床研究、认证文件、对比数据、授权与利益关系声明）才能完成时，归 CLAIM。判定固定三步：① 抽取断言强度（普通/强/绝对）与断言对象（本品/竞品/行业/人群）；② 核证据四匹配——存在性、主体匹配（本品/本型号/该人群）、口径匹配（终点/对照/样本/显著性/使用条件）、范围匹配（时间/市场/SKU/认证范围）；③ 任一不匹配即 CLAIM 违规，四项全匹配才通过。若缺陷无需调取任何证据材料、只需对照规格表/公开事实/科学共识即可判定，则按判定顺序先归 FACT（可在 secondary 记 CLAIM），不归 CLAIM。

**判定条件（可执行）：**

| ID | 条件（when） | 返回 |
|---|---|---|
| CLM1 | 句中（含标题、按钮、图片文字、口播）出现“本品/本成分/本服务能产生某生理、健康、行为或性能结果”的断言或等价暗示（more milk、reduce leakage、sleep better、7 minutes、pain-free、提升/改善/预防/促进）；结果本身未被一级来源明确否定；只接受可测量终点（数字、对照、量表、可复核测试），主观体验/情绪利益转 BRAND 除非给出可测量终点 | 命中 CLAIM |
| CLM2 | 句中出现与竞品、行业基线或自家旧款的比较（better than、vs、10x、22% slimmer、优于、完胜、秒杀、比同类），判定点是“对比对象 + 测试条件 + 数据来源是否写明且同口径” | 命中 CLAIM |
| CLM3 | 句中援引外部资质、等级、认证、奖项或排名（FDA approved/cleared、hospital grade、medical grade、获奖、#1、bestseller、top rated、销量第一），判定点是“该资质/排名对本品是否真实存在、范围与有效期是否覆盖”；**名称准确性（approved vs cleared/registered）不在本条件，归 FACT FCT4** | 命中 CLAIM |
| CLM4 | 句中出现专家、医生、IBCLC、机构、KOL 或“100+ experts”的推荐、调校或参与（recommended by、expert-tuned、ob-gyn recommended、专家推荐），判定点是“身份真实、确有推荐行为、参与深度与表述一致”；**COI 披露不在本条件，归 DISC DSC3**；没有可识别真人的泛称 → 仍归 CLM4，不归 RIGHT | 命中 CLAIM |
| CLM5 | 句中对本品使用 maximum、strongest、best、#1、唯一、100%、零风险、完全无声、never、every、fits all、永久等全称/最高级词描述产品利益、安全或适配，判定点是“是否有覆盖该词全部范围的证据”；该词必须指涉产品属性；无产品指涉的口号修辞 → BRAND BRD0 | 命中 CLAIM |
| CLM6 | 句子引用研究、文献、测试、百分比、样本量或统计显著性来支撑另一个断言（clinically proven、studies show、28% faster、statistically significant、A/B 测试），判定点是“研究能否外推到本品/该人群/真实使用条件、终点是否有临床意义、限定语是否保留”；直接证据 = 同产品、同人群、同终点、同使用条件的对照研究 | 命中 CLAIM |
| CLM7 | 句子把尚无直接证据、仅来自相关性/小样本/相邻产品/动物实验的结果写成已成立结论，或把“可能”写成产品终点；判定点是“证据强度是否匹配断言强度”；若规则只要求把局限写给受众 → DISC DSC2/DSC6 | 命中 CLAIM |
| CLM8 | 兜底，仅当以下全部成立：规则对象是面向消费者的品牌/产品宣称；规则要求取得/保留证据；FACT/DISC/RIGHT/CHAN 的条件均不命中；规则点名具体消费者断言对象；规则要求 {测试来源/对比口径/资质/专家证据} 之一 | 命中 CLAIM |
| CLM9 | 规则触发条件本身是“某宣称缺少 competent and reliable scientific evidence”，且规则义务是补证据/删除/降级断言 | 命中 CLAIM；若义务只是把证据缺口告诉受众，DISC 记 secondary（DSC2） |

**不属于本轴：**

- 只在陈述通用知识/指南结论，缺陷是内容过时、机制描述错误或与科学共识不符 → FACT。
- 只是产品客观规格、材质牌号/标准、尺寸、容量、适用年龄写错，可对照规格表直接核实 → FACT。
- 合规点是必须配免责声明、限定信息或显著披露 → DISC；免责声明不能反过来治愈无依据宣称。
- 只是口号、情绪话术、价值主张，或对竞品作无可核查维度的贬损形容（puffery）→ BRAND。
- 合规点是渠道能不能投、形式是否合规 → CHAN。
- 合规点是人格权、肖像、个人信息或 AI 合法性 → RIGHT。
- 合规点是画面中的危险行为或场景安全 → SCENE。
- 规则正文只有触发词或规则码，没有判定口径或处理动作 → NOT_A_RULE 或回源重抽，不硬判 CLAIM。
- 不得因 `rule_nature=prohibition` 就把绝对化/零风险规则改归 BRAND 或 CHAN；`rule_nature` 是正交字段，不决定主轴。
- 不得用原 `severity` 值反推主轴；severity 由主轴 + rule_nature + 影响面另行推导。
- `jurisdiction` 只决定适用哪套证明标准（US: competent and reliable scientific evidence/reasonable basis；EU/UK: substantiation；CN: 广告法绝对化用语等），不改变主轴。
- 方法学/统计口径规则（intent-to-treat、盲法、洗脱期、多重比较校正）没有具体消费者断言对象 → NOT_A_RULE，不进入 CLAIM 分母。

**与邻轴的分界测试：**

| 邻轴 | 测试 | 例 |
|---|---|---|
| FACT | 问“修这句话要改事实，还是补证据？”只需对照权威指南/规格表/公开事实就能判对错 → FACT；命题可成立但拿不出相称且范围匹配的证据 → CLAIM；同一句同时构成事实错误与证据不足 → FACT 先 | mimics baby 与解剖/生理事实不符 → FACT；faster letdown 拿不出本品测试数据 → CLAIM |
| BRAND | 用“是否有可测量终点/对照/数字/认证”判：点名了 → CLAIM；只有形容词/感受且无测量终点 → BRAND | More Milk, Less Stress 暗示奶量产出，可被证据复核 → CLAIM；Comfort in Every Session 只承诺主观舒适 → BRAND |
| DISC | 看规则要求的是“加披露”还是“有证据/降断言”：必须把免责声明、限定信息或结构/功能声明显著展示 → DISC；必须补证据、删除断言或降低断言强度 → CLAIM；证据缺口触发 → CLAIM primary、DISC secondary | Supports immune health 缺 CRSE → CLAIM；保留句子但未附“未经 FDA 评估”声明 → DISC |

**复核人。** CLAIM 复核员（广告/法规合规背景）人工一审；CLM1/CLM6/CLM7（功效、研究引用、待验证宣称）另加医学或注册法规复核。证据原件由宣称方（品牌/客户）提供并在工单留档，审查员只核验存在性与匹配性，不代拟、不补写证据。`confidence=low` 的规则与所有 UNKNOWN 必须人工终审。

**证据要求。** 分类判定先固定三样输入：规则原文、被审句、断言强度与对象标注；判违规须能指认一份可核验的证据材料并完成四匹配（存在/主体/口径/范围）。按宣称类型：① 功效与性能——competent and reliable scientific evidence，健康类须人体/受试者数据，对照或自身对照设计，统计显著且临床有意义的终点，完整报告（摘要不算），测试条件与真实使用一致；② 比较——对比对象、型号、测试条件、样本、数据来源与日期、同口径；③ 资质/等级——认证或注册文件（编号、签发机构、有效期、覆盖型号/SKU），名称准确（FDA cleared ≠ approved）；④ 排名/销量/评分——平台、类目、市场、时间窗、SKU 范围与统计方法；⑤ 专家/机构背书——身份与资质证明、实际推荐/参与证据、授权、参与深度与表述一致、利益关系披露；⑥ 绝对化/最高级——覆盖该词全部范围（全市场/全人群/全条件）的证据，拿不出则删除或改客观参数；⑦ 研究引用——研究原文及人群/终点/局限，正文保留限定语。缺任一材料或任一匹配不成立即违规；材料未提供 → UNKNOWN，不是通过。

## 5. 正交字段的取值与推导规则

### 5.1 `rule_nature` 五值

| 值 | 可判定特征 | 违规成立方式 | 典型动作 |
|---|---|---|---|
| `prohibition` | 禁止/不得/must not/may not/prohibited | 做了才违规 | 删除、替换、下架 |
| `mandate` | 必须/应当/需/must/should/required | 没做才违规 | 补做、补字段、改配置 |
| `disclosure` | 披露/标注/说明/告知/disclose/label/communicate | 受众信息元素 X 缺失/不完整/形式不合规 | 补披露、改显著度 |
| `substantiation` | 需提供证明/需附来源/需有依据/substantiate/competent and reliable evidence | 证据缺失/不匹配 | 补证据、降断言、删除 |
| `recommendation` | 建议/宜/recommended/should consider | 偏离建议或表述不当 | 改表述、改做法 |

**推导规则：**

1. `rule_nature` 从规则记录读取，不从主轴推断。
2. 一条规则含多个义务形态时，先拆原子；每个原子只保留一个 nature；primary 的 nature = primary 原子谓词的 nature。
3. 缺失或非法值 → UNKNOWN U7，不猜。
4. `rule_nature` 与 `form`（xlsx 的形态字段）只有 96/638（15.0%）重合，不得互换；也不得用 `rule_nature` 推 severity。

### 5.2 `jurisdiction` 枚举与多国拆条

| 值 | 含义 | 判定 |
|---|---|---|
| `GLOBAL` | 全球适用/无国家限制，且义务本身不依赖特定法域 | 规则文本明说 global/all markets，或没有国家指向且义务为通用知识/通用披露 |
| `US` / `CA` / `EU` / `UK` / `CN` / `BR` / `AU` / `SG` / `AT` / `BH` | 单一国家/地区 | 规则文本点名该国家/地区，或引用的法规/平台政策属于该辖区 |
| `PLATFORM` | 平台政策，不是国家法域 | 规则来源是平台政策/指南；可同时带国家范围 |
| `MULTI` | 文本点名 ≥2 个国家/地区 | 必须拆条；最终输出不允许 MULTI |
| `UNKNOWN` | 无法判定 | U7 |

**多国拆条规则：**

- 文本点名 ≥2 个国家，且义务相同：拆成每个国家一条，`parent_rule_id` + `split_index`，各自判 axis；不得写单一 GLOBAL。
- 文本点名 ≥2 个国家，且义务不同：按国家拆条并分别判 axis；不同国家的结论可以不同。
- 文本含 Austria/Australia/Bahrain 等多国：不得压成一个 EU；按国家拆。
- 文本含 Singapore/UK：当前 7 值枚举没有 UK/SG，必须扩展枚举；不得落 GLOBAL。
- `NA` 是废弃别名：文本明说 Canada → `CA`；否则 UNKNOWN。
- `GLOBAL` 不是“源字段为空”的同义词：源字段空 515 条中逐条判定为 GLOBAL 483、US 27、NA 2、PLATFORM 1、EU 1、CN 1；不得把空值直接当 GLOBAL。

### 5.3 `severity` 推导（L0–L5）

**影响面 I：**

| 级别 | 定义 | 例 |
|---|---|---|
| I3 | 人身安全、权利、未成年人、P0 一票否决、禁止投放品类 | 危险动作示范、儿童乘车、未成年人隐私、AI 冒充真人、禁投品类 |
| I2 | 核心消费者宣称/受监管宣称/法定强制披露/影响购买或使用的产品参数 | 功效承诺、认证等级、包装法定标识、吸力 mmHg |
| I1 | 辅助性事实/非核心知识/次要披露 | 非关键时间节点、补充说明、一般限定语 |
| I0 | 纯形式/编辑质量，不影响消费者决策 | 错别字、引用格式、配图、结构 |

**主轴基础分：**

| 主轴 | I0 | I1 | I2 | I3 |
|---|---:|---:|---:|---:|
| CHAN | 2 | 3 | 4 | 5 |
| RIGHT | 2 | 3 | 4 | 5 |
| SCENE | 2 | 3 | 4 | 5 |
| DISC | 1 | 2 | 3 | 4 |
| BRAND | 1 | 1 | 2 | 3 |
| FACT | 1 | 2 | 3 | 4 |
| CLAIM | 1 | 2 | 3 | 4 |

**义务形态修正：**

- `prohibition`：若规则是绝对禁止/P0（不得、must not、一票否决），+1；否则 +0。
- `recommendation`：−1（最低 L1）。
- `mandate` / `disclosure` / `substantiation`：+0。
- 法定强制标识（DSC5）最低 L3，不因 I1 降到 L2。

**重复修正：**

- 同一违规在 ≥3 条 rule_id 中出现，或跨 ≥2 个市场，+1；否则 +0。
- 重复计数必须在规则库去重后计算；同一事实的多条规则不重复加分。

**公式：**

```python
def derive_severity(primary, nature, impact, repeat=False):
    base = BASE[primary][impact]                  # 上表
    bump = 1 if (nature == "prohibition" and is_absolute(primary)) else 0
    bump += -1 if nature == "recommendation" else 0
    bump += 1 if repeat else 0
    return max(1, min(5, base + bump))
```

**硬约束：**

- L0 只用于 NOT_A_RULE / ALLOWED / 无违规；不得把 UNKNOWN 记为 L0。
- 不得沿用原表 `severity_raw` 或 `p_level`；原表 124 条 `severity=unknown`，其中 123 条是 E-2.x candidate（E-2.x 共 129 条，95.3%），不能当低风险。
- 同一 `rule_nature` 横跨 Critical–Low，不能反推 severity。
- 88.5% 这个数在 638 条表上无法复现（123/139 需要分母 139，但 139 不是本表可指认子集）；不要把它当校准基准。

### 5.4 `quality_tag` 使用边界

| 值 | 含义 | 使用条件 |
|---|---|---|
| `TYPO` | 错别字/拼写 | 不改变语义 |
| `GRAMMAR` | 语病/标点 | 不改变语义 |
| `STRUCTURE` | 章节/段落/顺序 | 不改变审查结论 |
| `TERMINOLOGY` | 术语统一/规范 | 不改变可判真假谓词的真值 |
| `REFERENCE` | 引用格式/年份/去重 | 不涉及证据是否充分 |
| `IMAGE` | 配图/示意图/缺失图 | 不涉及画面安全 |
| `FORMAT` | 排版/标题/标签 | 不涉及披露显著度 |
| `READABILITY` | 可读性/重复/冗长 | 不涉及情绪操纵 |
| `LOCALIZATION` | 本地化用词 | 不涉及法域强制要求 |

**规则：**

1. `quality_tag` 永不占 primary；形式问题返回 `status=QUALITY_ONLY`、`primary=None`。
2. 统计报表里的 `EDITORIAL` 是这组质量标记的桶名，不是 primary 值；27 条 EDITORIAL 全部按此处理。
3. `quality_tag` 可与任一主轴并存，作为“顺手要改”的标记；不得因为它存在就降低主轴的严重度。
4. 任何诉诸读者情绪/立场/语气的修改，即使只改一个词，也归 BRAND（可同时记 `EDITORIAL` 质量标记），不得只记 EDITORIAL。

### 5.5 `topic` 与 `confidence`

- `topic` 是源表主题/子类的描述字段，不参与判定；缺失时用 `subcategory_original` 回填；两者都缺失时置空并把 confidence 降一级。
- `confidence` 是判定元字段，不是概率；规则见 §2.5。`confidence=low` 必须人工终审；`confidence=medium` 必须抽检；`confidence=high` 可直接进入签发队列（P0 除外，P0 一律人工签字）。

### 6.11 去重后的系统性结论

115 项中，真正需要“新增轴/改定义”的根因只有 6 个，其余都是同一根因在不同 rule_id 上的表现：

1. **用“补救动作/整改结果”定义轴**（CHAN C1、SCENE/DISC、BRAND/EDITORIAL）：同一句因审查员选择不同整改方式而翻轴。修正：轴只由规则对象、内容谓词、渠道元数据决定，不由整改动作决定。
2. **把“证据缺失”同时写进 FACT、CLAIM、DISC**：同一“无来源”输入有三种结果。修正：FACT 只真值比对；CLAIM 证明责任；DISC 只信息元素；证据缺口触发 → CLAIM primary。
3. **把“披露”写进 CLAIM 的条件**（CLM4 COI、CLM7 标注）：同一句双命中。修正：COI/局限/风险/标识全部归 DISC；CLAIM 只判证据存在性与四匹配。
4. **把“平台自有标识”同时写进 CHAN 与 RIGHT**：同一子句双命中。修正：平台自有 → CHAN；平台外第三方 → RIGHT。
5. **把“AI 标识”同时写进 RIGHT 与 DISC**：同一义务双命中。修正：RIGHT 只授权链；AI 标识存在性/显著性/形式 → DISC；只有可识别真人未授权 → RIGHT。
6. **EDITORIAL 既被定义为 quality_tag，又被允许占 primary**：27 条规则无合法轴位。修正：EDITORIAL 永不占 primary；形式问题 → QUALITY_ONLY；情绪/立场/语气 → BRAND + quality tag。

这 6 条根因已经在 §2/§3/§5 写成硬条件；§6 的所有行都是它们的实例或数据回写。

- 依赖外部输入：源政策全文、条款号、版本/生效日期、平台政策快照。没有这些输入，不得把条目算作任何轴的“已覆盖”。

### 9.4 jurisdiction 枚举不完整

- 当前数据只有 7 值：GLOBAL 484、US 130、PLATFORM 18、EU 2、NA 2、CN 1、BR 1。
- 正文实际出现 UK、Singapore、Austria、Australia、Bahrain 等，7 值枚举装不下；E-2.94 同时点名 Singapore/UK，E-2.83 含 Austria/Australia/Bahrain。
- 本规范把枚举扩展为 GLOBAL / US / CA / EU / UK / CN / BR / AU / SG / AT / BH / PLATFORM / MULTI；`NA` 废弃为 `CA` 别名。
- 多国规则必须按国家拆条；最终输出不允许 `MULTI`。在枚举补齐前，多国条目只能标 `MULTI` 并挂起，不得压成 GLOBAL/EU。

### 9.6 severity 尚未校准

- 本规范的 L0–L5 公式是**提案**，不是已在 gold set 上校准的读数。
- 原表 `severity_raw` 是“文章审校优先级”，不是“义务强度”；124 条 `severity=unknown` 中 123 条是 E-2.x candidate，不能当低风险。
- 88.5% 这个数在 638 条表上无法复现（123/139 需要分母 139，但 139 不是本表可指认子集）；不要把它当校准基准。
- 校准方法：用 100 条人工双盲样本，按“主轴 + rule_nature + 影响面”独立打 L0–L5，计算与公式的 Spearman 相关和混淆矩阵；未达到 ≥0.80 相关前，severity 只作排序参考，不作对外等级承诺。

### 9.7 小样本与分布不可外推

- 复核后 SCENE 仅 4 条（0.6%）、RIGHT 2 条（0.3%）；不能据此判断全局分布，也不能因为条数少就降低 P0 审查强度。
- 七轴分布高度集中：FACT+CLAIM 占 82.6%（481/582）；DISC 10.7%；其余四轴合计 6.7%。这是本批 638 条的结构，不是内容审查的普遍结构。
- 子类主导轴统计（FACT 18 个/384 条、CLAIM 20 个/167 条等）只描述本批数据，不作先验概率使用。

### 9.8 重复计数与同源规则

- 同一事实错误在多条规则中重复：AAP 至少 12 个月出现在 W-2.40/W-2.42/W-2.130；盆底与分娩方式出现在 W-2.445/W-2.130；SIgA 出现在 W-2.293/W-2.353；E-2.99 与 E-2.112 正文/处理动作逐字相同。
- H04/U01 的触发词清单（`r-9b672eff05199974`、`r-c40ed52e71a07743`）与主规则同码重复，没有独立审查动作；应并入母规则作检测词表。
- 按 rule_id 计数会高估审查工作量；迁移时必须标 `same_source_group` 或去重，否则 638 条不是 638 个独立审查任务。

### 9.9 验证器尚未实现

- 本规范给出 V0–V5 的判据、门槛和可运行的数据门脚本，但 `classify(rule)` 和 `tools/verify_classification_spec.py` 尚未落地。
- 在验证器落地前，§7 的 `axis_exact`、`collision_rate`、`unknown_rate` 都是**待测**，不是通过；任何“规范已满足 MECE”的说法都必须附 V0–V5 的实际读数。
- 验证器自身必须遵守 AGENTS.md §2.4.4：`--selftest`/dry-run 不得写真实状态；同一输入两次运行输出必须一致；扫描器必须区分注释与代码。
- 在 V0 数据门转绿之前，规范的示例与分布只能作为**目标口径**，不能作为现状描述；当前现状是 §9.1 的 15 条未回写。
