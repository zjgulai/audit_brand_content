# 40 条披露模板重抽（2026-10-19）

> **一句话**：40 条空披露模板，**40/40 全部完成重抽**，每条都能指回 AF 原文的逐字子串。
> 但重抽过程中发现：**它们不是同一种东西** —— 真正可直接用于分类的只有 21 条。

产出：`research/governance/rule-rewrites-v1.json`

---

## 1. 怎么做的

1. 从 `规则清单-P0-P3-按等级-20261016.xlsx` sheet1 取 40 条的 **AF 列「逐字证据(evidence_quote)」**；
2. **人工逐条读** AF 原文（不是正则生成），写出三件事：触发条件 / 要求 / 处置动作；
3. 每条附一个 `evidence_span` —— **必须是 AF 里的逐字子串**；
4. 落盘前断言 `AF.find(evidence_span) >= 0`，**40/40 通过**。

★ 第 3、4 步是关键：没有 `evidence_span` 的「重抽」只是一段读起来像规则的话。
有了它，读的人可以自己 grep 回去核对，而不是只能相信我。

---

## 2. 结果分布：40 条不是同一类东西

| 类型 | 条数 | 含义 | 能否直接喂给 LLM 分类 |
|---|---:|---|---:|
| `content_rule` | **21** | 有明确触发 + 明确要求的审查规则 | ✅ 能 |
| `substantiation_rule` | **14** | 关于「证据/研究该怎么做」的规则 | ⚠️ 能，但它管的是**证据质量**不是**文案表述** |
| `not_a_rule` | **4** | 根本不是规则（章节导语、示例、元说明） | ❌ 不能 |
| `legal_citation` | **1** | 纯法条引用，无平台侧处置动作 | ⚠️ 需人工定它算不算规则 |

**所以「40 条重抽成功」这句话要拆开读**：
- **重抽本身 40/40 成功**（每条都有可核对的证据指针）
- **但只有 21 条是可直接使用的审查规则**

## 4. 三个必须说清楚的限制

### 4.1 证据有 3 条本身被截断

`r-7e243749e0eec06b`、`r-f4c5aed63e7f819f`、`r-4fdfb95997854147` 的 AF 原文以
`…[逐字摘录已截断，全文见 clause_units]` 结尾。

- 重抽的触发条件只用了**截断点之前**的内容；
- 这三条已标 `evidence_truncated: true`；
- `clause_units` **在本仓找不到**（全仓 grep 0 命中），所以拿不到后半段。
- ★ **这 3 条的规则是「不完整的完整」** —— 前面部分逐字可核，后面部分不知道有什么。

### 4.2 「substantiation_rule」14 条管的是研究，不是文案

例如 `r-64cde165077bc5fe`（研究须随机化）、`r-67ffdb69e67ca85b`（研究报告须有足够细节）。
它们**是规则**，但触发条件不是「广告里写了什么」，而是「你有没有按这个方法做研究」。

这对 LLM 分类有直接影响：**喂给模型的输入如果是文案，这 14 条永远匹配不上**。
它们该归到「证据充分性」这一类，而不是「文案表述」。

## 5. 一个方法上的取舍

我**没有**用正则从 AF 里自动抽「触发条件」。理由：

AF 是英文法律/指南原文，句式千变万化（`Advertisers are responsible for...` /
`should be sufficiently simple...` / `is prohibited on all supply`）。
自动抽取要么漏，要么抽出一堆半句 —— 而**抽错的规则比原始模板更危险**，
因为模板一看就知道是空的，抽错的规则看起来像真的。

所以这 40 条是**人工读出来**的。代价是慢，收益是每条都能核对。

## 6. 复现

```bash
# 证据指针自检：40 条 evidence_span 是否都还在 AF 原文里
python3 - <<'EOF'
import json, re, zipfile, xml.etree.ElementTree as ET
d = json.load(open('research/governance/rule-rewrites-v1.json'))
z = zipfile.ZipFile('规则清单-P0-P3-按等级-20261016.xlsx')
NS='{http://schemas.openxmlformats.org/spreadsheetml/2006/main}'
ns={'m':NS[1:-1]}
root = ET.fromstring(z.read('xl/sharedStrings.xml').decode('utf-8'))
strs=[''.join(t.text or '' for t in si.iter(NS+'t')) for si in root.findall('m:si', ns)]
ws = ET.fromstring(z.read('xl/worksheets/sheet1.xml'))
xr={}
for row in ws.iter(NS+'row'):
    c={}
    for cell in row.findall('m:c', ns):
        ref=cell.get('r'); col=''.join(ch for ch in ref if ch.isalpha())
        v=cell.find('m:v', ns)
        if v is None: continue
        c[col]=strs[int(v.text)] if cell.get('t')=='s' else v.text
    if c.get('G','').startswith('r-'): xr[c['G']]=c
bad=[i['rule_id'] for i in d['items']
     if i['evidence_span'] not in (xr.get(i['rule_id'],{}).get('AF') or '')]
print('span 校验失败:', bad or '无（40/40 全部可核）')
print('类型分布:', d['counts'])
EOF
```
