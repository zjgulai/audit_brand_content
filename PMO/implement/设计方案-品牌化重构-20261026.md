# 品牌设计方案 · 内容审核工作台（Momcozy 化重构）

> 对象：`/SUBMIT /INBOX /QUEUE /CASES /CASES/:id /APPEALS /RELEASE /TAKEDOWN /REPORTS /REPORTS/:id /TAXONOMY /ADMIN/GRANTS /ADMIN/SESSIONS /LOGIN`
> 依据：`www.momcozy.com` 2026-10-26 实景抓取（logo、品牌色、文案节奏、字体节奏）。
> 原则：**不是把电商页抄进审核台**。审核台的第一目标是「在异常里发现该动手的那一条」，
> 而不是「让人看完想买」。所以会**借 Momcozy 的颜色与语气，克制它的背景与装饰**。

---

## 一、品牌资产（已核实，不是估计）

### 1. Logo

| 项 | 值 | 来源 |
|---|---|---|
| 图形 | 心形左侧 + 文字标 `momcozy` | `logo-no1-pc.svg`（344×36，41 处路径，主色 **#6A2B3A**） |
| 放置 | 工作台侧边栏顶部（现在只是字母 `M`）+ 登录页头部 | 当前界面只有一个自造的 `M` 方块 |
| 例外 | 不放 favicon、favicon 沿用工作室圆形红底白 `M`（favicon 里的 logo 必须能被 16×16 识别，文字标会糊） |

> 落地：`web/public/brand/logo.svg`（SVG，透明底）。**logo 不做任何 CSS 变形**
>（不改变长宽比、不加阴影），只用原生尺寸或简单的相邻文字对齐。

### 2. 品牌色（按 momcozy.com 实测拆解，有限取用）

| 用途 | Momcozy 源码实测值 | 这个工作台怎么用（**克制**） |
|---|---|---|
| Primary | `#6A2B3A`（logo 主色、CTA 按钮底） | 主按钮、签字动作、当前选中态。**不到处用。** |
| Accent | `#C03D5A` / `#E593A5`（标题主色，电商的亮粉） | **不作为页面级背景** —— 大面积粉会让告警失效。做**标签光标色**与**高亮块**。 |
| Warm | `#F7E9EC`（浅粉背景，整板都是粉） | 主内容区背景**不是**它。它只能进**空态提示条**和**选中态 hover 底**。 |
| Text | `#2B1820`（电商标题的暗棕红） | 本工作台标题仍用中性炭黑（`--text`），**不**让所有文字都染上品牌红——品牌色一进文字就没有区别度了。 |
| Danger | `#E52E30`（电商红色） | **不用**。它跟 LOGO 红太接近，而本工作台的危险状态（BLOCK / error）必须是**红牌** —— 绝不能与品牌画等号。 |
| Neutral | `#fbf7f5`（电商米色 bg）、`#e6d9d5`（border） | `--bg` 仍用冷灰（Radix sand-2），方向板只用 `#e6d9d5` 做分隔线（作 `--border` 的变体，不是色谱色）。 |

**一句总纲**：**色板只用三种** —— 冷灰（非交互）、品牌酒红（高风险/重点）、**Warm 浅粉（选中/提示）**。
其它状态色（绿/琥珀/蓝红）**不借用品牌色**。

### 3. 字体（从电商站读出的节奏）

Momcozy 的字体节奏（实测）：
```
font-family: "Futura-PT", "Avenir", "Helvetica Neue", Helvetica, sans-serif;
标题：Futura-PT（几何现代，通过 600）
正文：系统默认
```
**映射到本工作台（不引入外挂字体）**：
- `--text-title` 用与 Momcozy 标题**同一类**几何 sans：中文场景用 `PingFang SC`,`Futura`, 或 `Avenir Next`，**字重 600**；
- `--text-base` 仍用系统 sans（不混入 Futura — 它会和正文节奏打架）。
- **不用 Momcozy 的大行高**（电子商务站会拉 1.8，审核台要扫读 1.4–1.6）。

### 4. 复制一颗**Momcozy 的调性情调**（文案口吻）

电商站文案的特征：**短句、你先、场景感**。例如 “Support，in Colors You'll Love”“Ready in Seconds”。
本工作台对应做法：
- 空态不再只说一句「队列为空」─ 要说 **「当前没有需要人工复核的内容。」**
- **不用「操作」「任务」这类通用词** —— 那是脚本语言。用业务动作：「检查」「处置」「签发」「下架」。

## 二、全站一致要做的事（14 页共用）

| 项 | 怎么做 | 为什么 |
|---|---|---|

| **登录页** | 顶部真实 logo + 一句话说明；**不要加品牌栏背景**（电商那一片大粉不要进登录页，它跟「进入工作场所」是两类情绪） | 登录页与电商的意图相反：它要克制 |
| **主 CTA** | 现有 `btn--primary` 改成品牌酒红 `#6A2B3A`<br>`hover = #4D1D29`（比主色深一档，不是加阴影） | 现在的 `#d13415`（tomato-11）与品牌 logo `#6A2B3A` 是**两个品牌色**，会互相吞掉 |
| **选中态** | 侧边栏当前项用 `--brand-surface` 粉浅底 + 品牌酒红字 + 左侧粗标志块（4px）<br>`since` 品牌有点凶，不要整片粉底 | 当前的粉现在是淡橙，不是 Momcozy 的暖粉 |
| **按钮文字可视化** | 主动作按钮：`font-weight: 600`，`letter-spacing: 0.01em`<br>副动作按钮：品牌酒红描边、**纯白底**，不填色 | 现在`btn`与`btn--secondary`差异不明显 |

## 四、不动的东西（同样重要）

1. **状态色**：绿（PASS）/ 琥珀（REVIEW）/ 红（BLOCK）/ 蓝（待检测）/ 紫（未测）。**不用品牌色换它们**，那是 A6 断言。
2. **黑白文本**：`--text`（sand-12）与 `--text-muted`（sand-11）。**不**加品牌红 —— 品牌色一进文字就没有区别度了。
3. **布局**：左侧边栏 + 顶栏 + 主内容区。不变成电商页那一张头图 + 网格（那是展示性的，不是工作度）。
4. **0.5px 边框**：仍然全部用 `--hairline`。
5. **字号** 12 / 14 / 18，只有三档。
6. **阴影**：仍然 0 阴影。

## 五、实现上的三条约束（防止方案不落地）

1. **所有颜色 token 都要过 `check_design_tokens.mjs`** —— 不允许出现裸 hex。品牌色只进 `tokens.css`，业务 CSS 只引用别名。
2. **任何颜色的对比度都要先测**：!['-brand']: '#6A2B3A' 与白字 ≥ 4.5:1（实测 7.52:1），与 `--brand-surface`（#F7E9EC）与 `--brand-text`（#6A2B3A）也 ≥ 4.5（实测 9.9:1）。
3. **logo 不许变样**：不给 logo 加阴影、灰度、缩放变化；只放原生尺寸或不改变长宽比的缩放。

## 六、验收清单（每页都跑的开发性门禁）

- `check_pages.mjs`：sidebar 一列、不折行、主内容不被挤压、`caseTable` 仍用 `found`
- `a11y_check.mjs`：15 条路由 × 2 视口 `0 violations`
- `check_bundle_budget.mjs`：新增品牌资产后首轮体积（`logo.svg` 32K → gzip 6–8KB，`logo.png` 5.5K）
- 视觉人看对接人（我自己）用 1280×720 与 390×844 两幅画面对比，（不是浏览截图读，文本与布局是否分开）。
