## 二、两个决定排序的发现

### 发现 A：复核动作在生产里是 501

```python
# api/write_api.py:528（生产分支）
# finding confirm/reject 不在首批生产能力内
raise HTTPException(501, "capability_not_enabled")
```

确认/驳回的真实实现在**旧 `_ledger_call` 分支**（`:550` 附近，走 `findings.transition`），
而生产 runtime **没有装配 `finding_store`**（`api/production_app.py` 里 grep 不到）。

**后果**：复核员能 claim / save_draft / submit，但**不能对任何 finding 点确认或驳回**。
这是内容审核产品唯一的真实动作。

### 发现 B（更严重）：`submit_review` 不要求 findings 已裁决

```python
# base/review_reducer.py:294
elif command == "submit_review":
    _require_claim(state, actor, expected_version, now)
    if not isinstance(conclusion.get("review_notes"), str) or not ...strip():
        raise LedgerValidation("bad_conclusion", ...)
    ... state["status"] = "closed"        # ← 直接结案
```

只校验 `review_notes` 非空。**一个 finding 都不看也能结案**，而且没有任何东西会红。

> 这两个合起来意味着：**当前「复核」在结构上是个橡皮图章，且它可以被合法地跳过。**

## 三、优先级排序（按主线可用性，不按工时）

| 序 | 事项 | 为什么排这个位置 |
|---|---|---|
| **P0** | ④ `confirm/reject` 生产接线 + `submit_review` 守卫 | 产品唯一的真实动作 + 它现在可被绕过。不做，前三个环节白通 |
| **P1** | 前端登录 + CSRF | 即使后端全通，真人一步也做不了（写必 403） |
| **P1** | ⑤ 报告 | 复核完无产物 = 做完等于没记录。**依赖 P0**（要有裁决过的 findings 才有内容可报） |
| **P2** | ⑥ 放行 | 依赖 P0 与 ⑤，先做也没东西可放 |
| **P2** | 部署最小件（Dockerfile + healthz） | 需授权；且前面未通时做等于把断链固化进镜像 |
| **P3** | PASS 不可达 / 绝对化 0 覆盖 / 内容更正路径 | 产品决策 + 数据工作，不阻塞「一个人用起来」 |

**一句话依据**：P0 决定「产品能不能做事」，P1 决定「真人能不能用」，P2 决定「能不能对外」，
P3 决定「做得好不好」。

## 五、一条数据侧的确认（**我写错过一次，这里是最正后的**）

`全球第一` / `100% 有效` 在 36 条规则里无命中。我起初说「**绝对化用语整族缺失**」——
**这是错的**。精确边界是：

```
规则库**有**的：最安全 / 100% safe / 唯一      （都在 T5.1.safety-claim 的 17 个关键词里）
规则库**没有**的：第一 / 最佳 / 100% 有效 / 有效
```

所以不是「整族缺失」，是**同一族里覆盖不全**：`最安全` 有，`第一` 没有。
参照上游 PRD 的原话（`PRD/feishu/内容审查Agent-PRD-v1.0.md:228-229`）：

> 【合规-绝对化用语】图片文字"最安全"为绝对化用语。
> 原因：**广告法禁止使用"最、第一、最佳"等绝对化用语。**

**上游点名的三个词里，规则库只有一个（「最安全」的变体）覆盖，「第一」「最佳」都没有。**

这是「补关键词 + 补正例」的工作，归 T-24（正例样本）+ T-25（规则覆盖），不是接线能解决的。
**当前后果**：BLOCK 只能靠医疗类与 safety-claim 类规则出现。

> ★ **我为什么写错**：我先查了规则**族清单**（`topic_label`），里面确实没有叫「绝对化用语」的族，
> 就据此下了「整族缺失」。但族名与关键词是两层 —— `safety-claim` 这个族里装着绝对化词。
> **拿一个层级（族名）的读数去断言另一个层级（关键词）的事实**，与 §2.4.1 是同一个形状。
