## 一 · 发送内容（模型实际写出来的那一段）

按 `tools/reply-cards/contract.md` §五：模型**不写卡片 JSON**，只写一个卡片块，V2 结构交给代码。

```
[[card:data-table]]
{"title":"你要的 4 件 · 逐条状态","verdict":"4 件里 2 件在我这边：岗位卡 50 份、PB 手册 8 份。需要的话我发你。","columns":["你要的","状态","在哪 / 判据"],"rows":[{"你要的":"岗位卡原文","状态":"有，50 份逐字全文","在哪 / 判据":"本机 agent-presets 的 agt-001…050，每份带原文与哈希"},{"你要的":"五份契约","状态":"材料里标注为「尚未实例化」","在哪 / 判据":"agt-002 岗位卡的状态行：五契约与 Bundle 尚未实例化"},{"你要的":"PB-007 / PB-008 手册","状态":"有，另有 pb-001…006，共 8 份","在哪 / 判据":"本机 skills 目录下 pb-007、pb-008"},{"你要的":"评测暴露的能力缺口","状态":"没有独立成件","在哪 / 判据":"只有 agt-004 岗位卡把它写成了岗位指标"}],"note":"我只扫了本机的文本文件（md/txt/json/html/csv），没扫全盘。"}
```

**选型理由**：4 行记录、字段相同 → `data-table`（`contract.md` §三第 2 条）。不是 `find-nothing` ——
因为 4 件里 2 件是**有**的；用「没找到」会把自己的读数说小。

## 二 · 降级形态（卡片被服务端拒掉时长这样）

由 `envelope.mjs` 的降级链自动产出，不是手写的第二版：

```
【你要的 4 件 · 逐条状态】
4 件里 2 件在我这边：岗位卡 50 份、PB 手册 8 份。需要的话我发你。
| 你要的 | 状态 | 在哪 / 判据 |
| --- | --- | --- |
| 岗位卡原文 | 有，50 份逐字全文 | 本机 agent-presets 的 agt-001…050，每份带原文与哈希 |
| 五份契约 | 材料里标注为「尚未实例化」 | agt-002 岗位卡的状态行：五契约与 Bundle 尚未实例化 |
| PB-007 / PB-008 手册 | 有，另有 pb-001…006，共 8 份 | 本机 skills 目录下 pb-007、pb-008 |
| 评测暴露的能力缺口 | 没有独立成件 | 只有 agt-004 岗位卡把它写成了岗位指标 |
我只扫了本机的文本文件（md/txt/json/html/csv），没扫全盘。
```

**边界被刻意放在 `note` 而不是 `subtitle`**：`subtitle` 不出现在纯文本降级形态里，
放那儿的话一旦降级，**限定条件会跟着消失** —— 对方看到的就成了一句没有范围的全称判断。

## 三 · 这条草稿里**不许出现**什么（D5 的防线，`守衡-知识库构建完整方案` §四）

| 不许出现 | 为什么 |
|---|---|
| 「我去接进来 / 我把它纳入知识库 / 后续我会索引它」 | 这是**范围决策**，D5 已定「不进」。承诺了就是替委托方改了范围 |
| 「这几件你得找某人」 | 我们**不知道**那是谁。指不出对象的话不许说（`AGENTS.md` §2.4.1） |
| 任何工具名、扫描命令、`timeout`、栈帧 | `守衡语域` §2.3：**故障不能变成内容**。这条回话是补上一次故障的，更不能自己再犯 |
| 「抱歉这么久才回」以外的任何道歉展开 | 同 §三第 1 条：不做开场白，也不做结语 |
| 「未实例化」改写成「我们没有」 | 两者不是一回事。前者是**材料自己写的状态**（`agt-002` 原文），后者是我们替材料下的结论 |
