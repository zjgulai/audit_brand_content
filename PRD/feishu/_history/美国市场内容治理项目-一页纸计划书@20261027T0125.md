1. 背景与问题
内容中的错误示范可能造成消费者误解或模仿，直接损害母婴品牌专业信任，并影响达人合作意愿，带来投诉、下架、返工和投放损失。当前主要痛点是：标准不统一、审查依赖个人、审核记录不完整。第一阶段先解决“能不能这样发”，不评价创意质量和转化效果。

2. 项目目标
建立统一的内容底线风险审查机制，形成“知识库 + 规则 + Agent 预审 + 人工复核 + 负责人确认”的闭环。  
可衡量目标：
试点品线美国市场新增内容 100% 上线前经过统一审查；
完成 4 类知识库 v1、第一版审查规则、统一 Agent 审查入口；
REVIEW / BLOCK 内容闭环处理率 100%，负责人 sign-off 覆盖率 100%；
重大红线问题 0 漏放，审核记录可追溯、版本可绑定；

3. 范围与交付物
待细化
做什么：美国市场新增内容；三条产品线；文字 / 图片 / 视频；亚马逊 / 独立站 / 社交媒体；
不做什么：历史内容暂不全面倒查；非美国市场暂不覆盖；不替代法务、医学、专家的最终判断；不评价创意质量和投放效果。  
最终交付：统一 Agent 审查入口；四类知识库与第一版规则；PASS / REVIEW / BLOCK 三态流程；审核记录、版本绑定和反馈机制；品线/部门负责人 sign-off 机制；试点复盘与验收报告。

4. 方案与实施路径
本阶段不是“让 Agent 自动审核”，而是建立一套统一治理工作流：

4.1. 内容发布审查流程
统一提交：内容负责人提交完整发布内容、版本、渠道、产品信息。
Agent 预审：基于知识库和规则，对文字、图片、视频进行风险识别，输出风险点、原因、修改建议和分流结果。
三态结果：
PASS：未发现已知底线问题，进入发布确认；
REVIEW：需要进一步判断，转北美团队 / 医学顾问 / 法务合规 / 专家；
BLOCK：命中明确红线，修改后重新提交。
人工复核：专业团队处理 REVIEW；高风险内容双人复核；所有结论留痕。
负责人确认：品线/部门负责人基于审查记录确认风险关闭、版本一致，完成 sign-off。
记录迭代：审核记录绑定发布版本，人工反馈回流知识库，定期更新规则。
