产品：内容审查 Agent

1. 背景与目标
1.1 背景
美国市场内容产出量大、审核机制不统一：
广告二创月均约 500 条，高峰约 3000 条，当前无固定审核机制，是最高风险端口。
吸奶器品线红人内容月均 100-200 条，已有两轮审核，但规则未完全统一。
品牌设计部 AI 平面素材每日产出，核心痛点是通识常识错误。
品牌社媒、PR、专家、独立站内容分散在 NAS、GD、飞书 Drive、Figma 等多处。
法务仅固定覆盖 listing、TVC、上市物料包、EDM，高频内容无固定介入通道。

1.2 目标
建立统一的内容发布前审查 Agent，实现：
排雷：识别消费者安全、品牌信任、合规、经营风险，覆盖 brief 与发布前完整内容。
分流：PASS / REVIEW / BLOCK 三态结论，自动转交对应负责人。
提效：降低人工逐条审核负担，优先处理 REVIEW / BLOCK。
留痕：审核记录绑定版本，支持统计、复盘、知识库回流。
准确：预审结论争取达到 90% 以上准确性，避免给人工复核增加麻烦。

5. 功能需求

5.1 输入方式
方式一：飞书群 @Agent 预审
内容提交方在飞书群直接 @Agent，发送文字、图片、视频、链接或文件。
brief 支持：直接粘贴文字、发送飞书文档链接、上传 Word / PDF。Agent 解析文字内容；若 brief 含图片/视频参考，按对应能力审查，第一阶段以文字为主。
Agent 自动识别内容类型和内容阶段（brief / final_content），调用对应审查能力。
输出三态结论（详见 5.3 输出规范）。
支持 @ 指定下一步审核人，或由 Agent 按规则自动 @。
方式二：批量上传 + 批量扫描
内容批量上传到指定位置：飞书多维表、NAS 共享盘、结构化 URL 列表。
多维表需包含“内容阶段”字段，可筛选 brief 或 final_content。
Agent 批量扫描后：
输出整体结论摘要；
在飞书多维表中批量生成每条内容的审查结论；
支持按 PASS / REVIEW / BLOCK 筛选、导出、统计。

5.2 审查能力

brief 审查重点：

合规底线：禁用词、医疗宣称、绝对化用语、目标市场法规。
产品宣称：功能边界、型号差异、认证表述。
达人披露：广告属性、合作披露要求。
不审创意方向、不审投放策略、不审转化目标。
审查维度：
消费者安全：错误示范、危险使用、误导性操作。
品牌信任：专业性受质疑、公开点名、达人争议。
合规：法规、平台政策、医学宣称、广告用语、绝对化用语。
经营风险：投诉、下架、返工、投放损失。
产品准确性：功能边界、型号差异、允许/禁止描述。


5.3 结论输出规范
Agent 输出结论时，必须先标注问题维度，再给出总结和建议。为降低人工复核压力，引入 SUGGEST（建议修改） 状态，不阻断发布流程。
5.3.1 问题分类枚举
合规、消费者安全、品牌信任、经营风险、产品准确性、措辞表达、人物肖像与 AI、其他。
5.3.2 定义与边界

SUGGEST 规则：
仅由 P3 层级（措辞与表达）或 P2 中轻微瑕疵触发。
飞书/系统回复时，在 PASS 结论下单独列一段“优化建议”。
5.3.3 输出字数与格式硬约束
单条问题：描述 ≤50 字，原因 ≤50 字，修改建议 ≤30 字。
位置：必须精确到“图 N 第 X 处”、“视频 00:12”、“正文第 X 段”。
依据：必须写“《文档名》第 X 条”或“规则 ID”，禁止写“相关法规”。
语言：客观、指令式。禁止“可能”、“建议可以考虑”等废话（除非是 REVIEW 的边界说明）。
5.3.4 各状态输出模板
PASS（≤50字）：

【PASS】未发现已知底线风险。可转交 @陈静姝 sign-off。
PASS + SUGGEST（≤150字）：

【PASS】未发现底线风险，但发现 1 处优化建议：
【措辞表达】正文第 2 段“超级好用”偏口语。建议：改为“高效便捷”。
可转交 @陈静姝 sign-off。
REVIEW（1-2个问题，≤200字）：

【REVIEW】发现 2 处需人工确认：
【合规-医疗宣称】视频 00:12 字幕“治疗堵奶”。原因：涉嫌医疗宣称。依据：《合规措辞库》第 3.2 条（链接）。
【安全-使用姿势】图 1 吸奶器姿势可能误导。原因：易致误解。依据：《产品描述库》第 2.1 条（链接）。
建议转 @法务 @医学顾问 复核。
BLOCK（1-2个问题，≤200字）：

【BLOCK】发现 2 处必须修改：
【合规-绝对化】图 2 文字“最安全”。原因：绝对化用语。依据：《禁用语》第 1 条（链接）。建议：改为“经过安全测试”。
【安全-车内】视频 00:08 未坐安全座椅。原因：危险示范。依据：《车内规则》第 1 条（链接）。建议：替换为正确画面。
请修改后重新提交。
问题 ≥3 个（汇总，≤100字）：

【PASS/REVIEW/BLOCK】共发现 X 处问题。
· 合规类：X 个 · 消费者安全类：X 个 · 措辞类：X 个
→ 查看完整清单：https://...（链接）
（若 REVIEW 加：建议转 @法务；若 BLOCK 加：请修改后重新提交。）

5.3.5 报告链接
触发条件：issue_count >= 3。
报告内容：按维度分组，包含位置、问题、原因、依据链接、建议。

6. 规则优先级与分层审查机制

6.1 设计背景

不同规则类型对模型推理的需求、响应速度和审查准确率要求差异显著。法务合规类规则命中即需拦截，常识性错误需要语义理解，措辞规范相对可容忍。如果不做分层，所有规则走同一推理链路，会导致两个问题：一是法务红线规则被模型“过度推理”后误判为不违规，二是大量低风险内容消耗模型算力、降低整体吞吐效率。

行业内容审核的通行做法是采用漏斗式分级过滤：第一层快速拦截（关键词、规则引擎），第二层深度推理（大模型语义理解），第三层人工复核。轻量规则先跑，大模型算力只用于真正需要深度理解的少数内容。

6.2 规则优先级分层设计

将审查规则按业务紧要性、监管要求和风险严重程度分为四个优先级层级，不同层级使用不同的审查策略和模型能力：


6.3 分层执行流程

内容输入
  ↓
P0 快速扫描 → 命中即 BLOCK 锁定
  ↓
P1 安全准确性（语义） → 明确违规 BLOCK，模糊 REVIEW
  ↓
P2 通识常识（多模态） → 明显错误 BLOCK，轻微/模糊 REVIEW 或 SUGGEST
  ↓
P3 措辞建议 → 统一输出 SUGGEST
  ↓
汇总四态结论

规则：
P0 命中即 BLOCK，默认停止后续扫描以节省算力。
P1/P2 并行，按最高级别输出；同一内容可同时有 BLOCK 和 SUGGEST，最终状态为 BLOCK。
P3 仅为 SUGGEST，不影响最终拦截状态。
无 P0、P1、P2 明确违规，仅存在 P3 SUGGEST 时，系统最终流转状态（decision字段）输出为 PASS，同时在结论中附带 SUGGEST 建议清单。
状态优先级：BLOCK > REVIEW > PASS。只要命中更高级别，低级别建议降级为备注或直接忽略。

6.4 行业实践依据

内容审核行业的核心做法是“规则优先级分层 + 分级匹配”：

权重分配：将规则分为硬性规则（违法违规内容）和软性规则（低质量文本），硬性规则权重最高（例如权重 10），软性规则次之（例如权重 5）。

分级匹配：第一层高频硬性规则快速匹配（关键词黑名单），匹配成功立即处理；第二层低频软性规则异步检测（语义分析），降低延迟。先用正则匹配敏感词（毫秒级响应），再调用 NLP 模型分析语义（秒级响应）。

冲突解决：当多条规则同时命中时，采用“最高权重优先 + 人工复核兜底”模式。例如，一条内容同时命中广告规则（权重 50%）和涉政规则（权重 90%），系统优先拦截涉政内容。

漏斗式三层架构：第一层快速拦截（关键词、规则引擎和轻量模型），第二层深度推理（中高风险内容进入大模型审核层），第三层人工复核（边界模糊、高敏感度内容）。

本 PRD 的 P0-P3 四层设计即基于上述行业实践，结合母婴品类审查场景做了适配。

9. 人工复核与 sign-off

REVIEW 自动转对应专业团队（法务、医学、专家、北美）。
BLOCK 返回内容方修改，修改后重新提交。

REVIEW 已有人工结论；
BLOCK 已修改并重新提交；

人工复核结论回流知识库，更新规则权重和正负样本。

10.3 抽检
每两周抽检已 PASS 内容 ≥100 条或 5%，取高者。（提供随机抽检列表）

11. 准确性要求与评估
11.1 目标
整体四态准确率 ≥ 90%。
BLOCK 精确率 ≥ 95%。
P0 漏报率 = 0。
SUGGEST 不纳入硬性准确率考核，但需控制误报量（不影响发布）。
评估以人工复核和抽检为准。
11.2 评估方式
以人工复核和每两周抽检（100 条或 5%，取高者）为金标准。
准确率 = 三态结论一致数 ÷ 总审查数。
BLOCK 精确率 = 正确 BLOCK ÷ 全部 BLOCK。
P0 漏报率 = P0 应命中未命中数 ÷ P0 应命中总数。
不达标时，优先修规则、补样本、调模型。
12. 非功能需求

脱敏轻量原则：
内部审核已单独开权限的，可不强制打码。
报告链接、导出文件、模型训练样本、日志，建议脱敏或去标识。
不对外分享、不训练、不导出时，仅靠权限控制即可。
13. 权限与安全
