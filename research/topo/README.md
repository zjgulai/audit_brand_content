## 四、两处必须知道的不一致

### ① `外部标准库`(62) 与 `规则库`(50) 是**同一批数据的两个投影**

共有 50 条，**`条款原文` vs `原文逐字` 逐字节相同 50/50**。字段名不同、视图不同：

| 字段 | 外部标准库 | 规则库 |
|---|---|---|
| 主键 | `条目ID` | `规则ID` |
| 原文 | `条款原文` | `原文逐字` |
| 链接 | `出处链接` | `来源链接` |
| 桥 | `关联规则` | `关联现网规则` |
| 状态 | `法务结论`=待确认 | `状态`=研究稿 |
| 专有 | `来源机构` `性质` `我方标注` `法务备注` `适用品线` | `规则类型` `规则来源` `适用品类` |

`规则库` 缺 `来源机构`（**权威来源轴只有外部标准库有**）。
64 条唯一 = 50 共有 + 12 英国（只在外部标准库）+ 2（EXT-059~062 TikTok 只在外部标准库）。

★ **确认状态：0 条被确认过。** 外部标准库 `确认人` 0/62、`确认日期` 0/62；
规则库 `确认人` 0/50。`我方标注` 62/62 全为「研究稿·未经法务确认」。

## 七、四条互不连接的入库通道（2026-10-17 实测）

知识库不是「一个库缺材料」，是**四条通道各自入库、彼此零引用**：

| 通道 | 条数 | 材料来自哪 | 出处字段指向 |
|---|---:|---|---|
| ① 外部标准库 | 62 | **直接网上调研** | `出处链接` → 8 个外部网站（FDA/FTC/Amazon/…）|
| ② 规则库 | 50 | ①的投影 | 同①（50 条逐字节相同）|
| ③ 负面样本 | 183 | **飞书群「设计审核」扫描** | `来源` → 183/183 全是该群 |
| ④ 材料收集 | 32 | **对接人手工提交**（**14 人**，实测去重）| `材料链接` → 飞书节点 |
| ⑤ 主 Base 规则源 | 21 | **W1卖点表达边界 / 红绿灯 xlsx** | `依据来源`（3 个来源）|

**交叉核验（两条都为 0）：**

```
材料收集的标题 ∩ 外部标准库的「来源文档」  = ∅
负面样本的「来源群」∩ 材料收集的标题      = ∅
```

★ **不是「材料收上来了没蒸馏」** —— 是**外部标准库根本没从材料里长出来**。
它的 62 条全部来自直接调研；而材料收集里那 7 条被标成「外部标准」的，
